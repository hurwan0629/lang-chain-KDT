# 환경변수에 대해서
환경변수는 기본적으로 프로세스가 돌아갈 때 할당되는 메모리 안에 환경변수 블록을 생성하여 필요할 때마다 해당 변수를 읽는 방식을 사용합니다.

또한 윈도우에 존재하는 환경변수의 경우에는 모든 프로세스가 실행 될때마다 해당 데이터들을 복사하여 실행하게 됩니다.

![윈도우 환경변수](image.png)

이 때문에 자바를 깔았을 때 프로세스가 `%JAVA_HOME%`를 사용할 수 있게 이곳에 등록하는 이유가 됩니다. 항상 동일하게 접근하기 위해. 파이썬과 여러 프로그램의 경우에도 동일한 경우가 많습니다.

## `.env`
일반적으로 프로그램(프로세스)를 실행할 때 환경 변수가 필요한 경우에는 `*.env*` 형태의 파일을 사용합니다. 여기에서 해당 파일은 존재 자체로는 특별한 역할을 하지 못하며 그냥 데이터가 새겨진 파일일 뿐이 됩니다.

대표적으로 js의 `dotenv` 라이브러리가 존재합니다.

보통 `dotenv`의 `default export`인 `dotenv` 객체의 `.config()` 메서드를 작성하게 된다면 `dotenv`가 현재(루트 아님) 폴더의 `.env` 파일을 읽은 뒤 `process.env`에 변수를 넣어주게 됩니다. 예를 들어 `SECRET=12345`였다면 `process.env.SECRET`를 통해 접근이 가능하게 되며 해당 값이 존재하지 않으면 `undefined`, `.env` 이외의 파일은 `.config({ path: '.env.local'})`과 같은 다른 파일의 경로를 직접 지정이 가능하게 됩니다.

자바의 경우에는 보통 `System.getenc()` 또는 `System.getProperty()`(환경변수와 JVM 시스템 속성)이 존재하며 스프링을 사용할 경우에는 `Spring Enviroment`라는 객체를 통해 관리하게 됩니다.

## Powershell
종종 `Powershell`에서 특정 프로그램, 예를 들면 `python main.py`를 실행했을 때 실행되지 않는 경우가 있는데 이는 대체로 `python.exe`의 경로가 지정되지 않은 것이며 `$env:python`을 통해 확인 가능합니다. 임시로 설정하려면 `$env:python = [경로]`와 같이 설정도 가능합니다.

환경변수의 동작

환경변수는 프로세스가 실행될 때 할당되는 메모리 안에 환경변수 블록을 만들고, 필요할 때 해당 값을 읽는 방식으로 사용됩니다.

Windows에서는 새 프로세스가 시작될 때 부모 프로세스의 환경변수 블록을 복사해 전달합니다. 시스템이나 사용자 환경변수를 변경하더라도 이미 실행 중인 프로세스에는 곧바로 반영되지 않는 이유입니다.

Windows 환경변수 설정

Java 설치 후 JAVA_HOME을 환경변수로 등록하는 것도 여러 프로세스가 Java 설치 경로를 일관된 이름으로 참조할 수 있게 하기 위해서입니다. Python을 비롯한 여러 프로그램도 같은 방식을 사용합니다.

.env 파일

프로그램을 실행할 때 환경변수가 필요하면 흔히 .env 형식의 파일에 값을 기록합니다. 파일 자체에 특별한 기능이 있는 것은 아니며, 프로그램이나 라이브러리가 파일을 읽어 환경변수로 로드해야 합니다.

JavaScript에서는 대표적으로 dotenv 라이브러리를 사용합니다. dotenv.config()를 호출하면 기본적으로 현재 작업 디렉터리의 .env 파일을 읽어 process.env에 값을 추가합니다.

예를 들어 파일에 SECRET=12345가 있다면 process.env.SECRET으로 접근할 수 있습니다. 값이 없으면 undefined가 반환되며, 다른 파일을 사용하려면 dotenv.config({ path: ".env.local" })처럼 경로를 지정할 수 있습니다.

Java에서는 환경변수를 System.getenv()로, JVM 시스템 속성을 System.getProperty()로 읽습니다. Spring에서는 Environment 객체를 통해 이 값들을 통합해서 다룰 수 있습니다.

.env에는 비밀번호나 API 키가 들어갈 수 있으므로 일반적으로 버전 관리 대상에서 제외합니다.

PowerShell에서 확인하기

PowerShell에서 python main.py가 실행되지 않는다면 대개 python.exe가 있는 디렉터리가 Path 환경변수에 포함되어 있지 않기 때문입니다.

현재 세션의 경로 목록은 $env:Path로 확인합니다. 임시로 경로를 추가하려면 $env:Path = "C:\Python312;$env:Path"처럼 설정할 수 있으며, 이 변경은 현재 PowerShell 프로세스와 그 자식 프로세스에만 적용됩니다.
