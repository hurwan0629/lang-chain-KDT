# 메모리에 대한 이해
이번에는 C의 포인터와 특징을 이해하기 위해, 기존에 알던 메모리 영역에 관한 지식을 조금 더 확실하게 정리해두려 합니다.

## 메모리의 형태
일단 `C`에 대해서 알아보기 전에, 메모리 영역에 대해 먼저 알아보려 합니다.

일반적으로 운영체제에서 할당해준다고 하는 메모리는 RAM을 말합니다.

메모리는 스택, 힙, bss, 데이터, 코드 영역으로 나뉘어 있습니다.

이중에서 스택은 자동으로 프로그램에 쌓였다가, LIFO 방식으로 정리되어 사라지는 방식으로 관리하는 데이터 영역입니다. 함수 호출 순서, 지역 변수, 리턴 주소 등이 일정 생명 주기 동안 생성되었다가 사라집니다.

반대로 힙의 경우에는 개발자가 필요에 따라 할당받도록 프로그래밍하여 일정 양의 공간을 받아서 사용한 뒤 반납하는 공간입니다. Java, Python의 경우에는 자동으로 정리되지만, C에서는 일반적으로 개발자가 직접 메모리 주소를 통해 접근하게 됩니다.

bss와 데이터 영역은 모두 전역/정적 객체가 저장되는 공간입니다. 둘 다 프로그램 전체 생명 주기 동안 살아있어야 한다는 공통점이 있습니다. 차이점은 bss에는 초기화되지 않았거나 0인 데이터들이 모이며, 프로그램 런타임에 0을 채워 넣어 공간을 절약하기 위한 영역입니다.

코드 영역은 이름 그대로 C 기준으로 컴파일된 코드가 저장되는 영역입니다. 보통 읽기 전용으로 존재합니다.

## C에서의 메모리 관리 방법
C에서는 메서드나 객체라는 개념보다는 함수와 구조체라는 개념이 존재합니다. C의 특징을 말하자면 고급 언어 중에서는 로우 레벨에 가깝고, 포인터라는 주소 참조 기능을 통해 주소로 객체에 직접 접근할 수 있습니다.

예를 들어 `int *p;`는 `int` 변수의 주소를 가리키는 포인터 변수 `p`를 만드는 표현입니다. `p`에는 대상 변수의 주소가 들어 있고, 주소를 통해 값을 꺼내기 위해서는 `*p`를 사용합니다.

메모리 주소 할당은 `malloc(받을 메모리 크기)` 함수를 통해 구현할 수 있습니다. `malloc()`의 반환값은 만들어진 공간의 시작 주소입니다.

`int *p = malloc(sizeof(int))`를 통해 받은 힙 메모리는 `free(p)`를 통해 반납합니다. 이후에는 예외 상황을 줄이기 위해 보통 `p = NULL`로 만들어 둡니다.

> 추가적으로 메모리 공간을 할당해주는 `malloc()` 외에도, 공간을 다시 `0`으로 초기화해주는 `calloc()`과 기존 데이터에 이어 새 공간을 받기 위한 `realloc()`도 존재합니다.

아래는 이해를 돕기 위한 테스트 코드입니다.

```C
#include <stdio.h>
#include <stdlib.h>

// 메모리 영역에 대한 정리
// 메모리의 형태
/* * * * * * * * * * * *
[stack] - 지역 변수, 매개변수, 함수 호출 정보가 저장되는 공간
         stack 메모리는 필요할 때 아래로 확장
         [           유휴 공간 존재           ]
         heap 메모리는 필요할 때 위쪽으로 확장
[heap] - 동적으로 할당되는 변수나 객체가 저장됨
[bss] - 초기화되지 않은 전역 변수 및 정적 변수
        초기화되어도 위치가 바뀌지 않음. 런타임 시점에 메모리 할당 후 0으로 채워 초기화
[data] - 초기화된 전역 변수 및 정적 변수
[code] - 프로그램의 실행 명령이 저장되는 읽기 전용 공간
* * * * * * * * * * * * */

// bss 영역으로 이동
int varBss1;
int varBss2 = 0;

// data 영역으로 이동
int a = 1;

// 현재 파일에서만 접근 가능한 변수로 이동 (/data)
static int varBss3 = 10;

int* counter() {
  printf("\n --- counter() --- \n");
  // bss 영역에 존재
  static int count = 0;

  printf("counter().count++ = %d\n", count++);
  // stack에 anchor 생성
  int anchor = 10;
  printf("counter().anchor = %d\n", anchor);
  printf("counter().anchor addr = %p\n", &anchor);

  return &anchor;
}

int* getIntArray(int size) {
  int* arr = malloc(sizeof(int) * size); // 4 * size

  return arr;
}

int main() {
  for(int i=0;i<10;i++){
    int *anchor = counter();
    printf("anchor addr: %p\n", anchor);
    // printf("anchor: %d\n", *anchor);

    printf("\n --- counter() return anchor --- \n");
  }

  int size = 10;
  int* arr = getIntArray(size);
  for(int i=0;i<size;i++) {
    *(arr + i) = i*10;
  }

  for(int i=0;i<size;i++) {
    printf("%d ", arr[i]);
  }
  printf("\n");

  free(arr);
  // printf("after free(arr); arr = %p", arr);
  arr = NULL;
  printf("after arr = NULL; arr = %p", arr);
  return 0;
}
```
