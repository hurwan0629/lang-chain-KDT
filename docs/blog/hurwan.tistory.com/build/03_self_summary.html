# 컴퓨터에 대해서 스스로 정리해보기 - [기본 구성 요소]
> 이번에는 운영체제와 컴퓨터가 이루어진 방식을 스스로 정리하는 시간을 가지려 합니다. 

## 컴퓨터의 발전 흐름

진부한 이야기지만 컴퓨터는 그냥 저장과 생각을 대신 해주는 장치입니다.

초기의 컴퓨터는 그냥 사용자가 직접 기계어를 입력하고 자기가 만든 프로그램 같은 것을 컴퓨터에 넣으면 그 계산을 실행해주는 모습이었습니다.

발전 과정을 알아보면 이런 느낌입니다.

### 0. 시초의 컴퓨터

사람들이 줄 서서 자기가 만든 프로그램 입력하면 그 계산이 나오는 것

### 1. 일괄 처리 시스템(Batch System)

여러 사람들이 자기들의 프로그램들을 한 번에 등록해서 순서대로 처리하는 것 (이때 `I/O` 대기 같은 걸 기다리는 **동기식 형태**)

### 2. 스풀링

위에서 말한 동기식 문제에 의해 입출력 작업을 디스크(현대로 따지면 `HDD`)에 저장해 놓고, 거기에 대기 순서 붙여놓고 다른 `CPU` 작업 하는 것

### 3. 다중 프로그래밍

슬슬 현대 컴퓨터의 느낌을 주기 시작하면서 한 번에 여러 작업들을 메모리에 올려놓고, 하나가 입력을 기다리면 `CPU`가 다른 프로그램을 실행하는 방식. 슬슬 시스템의 사용성을 높이기 시작함

### 4. 시분할 시스템

여러 사용자가 순서대로 기다리는 것은 동시에 프로그램을 2개 이상 돌리면 멈칫거리는 것처럼 나타날 수 있으니 여러 프로그램을 한 번에 돌릴 수 있게 **라운드 로빈 방식**으로 `CPU`를 나눠줌 (주어진 사용 시간을 **타임 퀀텀**이라고 함) (이때부터 대화식 시스템에 가까워짐)

### 5. 실시간 시스템

시스템이 빠르고, 반드시 **정해진 시간 안에 응답**하게 하는 시스템.

### 6. 개인용 컴퓨터

이전에는 사용자들이 전화번호 연결 요청하듯이 중앙 컴퓨터를 같이 돌려썼지만 이제는 개인용 `PC`가 주어지게 됨. 

### 7. 분산 처리 시스템

여러 컴퓨터가 자신의 역할을 갖고 네트워크를 통해 서로 통신하며 작업을 수행. (서버를 따로 두는 **마이크로서비스**가 그 예시임)

### 8. 멀티코어

한 컴퓨터에 여러 `CPU` 또는 코어를 두게 되면서 작업을 병렬적으로 돌릴 수 있게 되었음. 여기서부터 병렬 작업의 프로세스간의 메모리 참조 등에도 더 주의를 가져야할 필요가 생겼습니다.

## 컴퓨터의 구성 요소

컴퓨터는 아래와 같은 구성 요소로 이루어져 있습니다.

### 하드웨어

#### 디스크(HDD)

물리적으로 자석과 디스크(원판)를 통해 저장되는 저장 공간입니다. 많은 양의 데이터가 저장 가능하지만 상대적으로 느립니다.

#### 메모리(RAM)

`CPU`가 디스크보다 빠르게 접근 가능한 전자 신호로 저장되어 있는 휘발성의 저장 공간입니다. `ROM`과 `FLASH` 같은 비휘발성 저장 공간 또한 존재합니다.

#### 버스

컴퓨터 내부에서 데이터가 이동하는 통로입니다. 전자가 통하는 구리 배선 같은 걸 통해 `0`/`1` 데이터가 흘러다닙니다. 주로 **데이터**, **주소**, **제어**, 경우에 따라 **인터럽트(제어)** 버스가 존재합니다. 

#### CPU

아키텍처에 따라 각자 실행 가능한 명령어들의 묶음으로 이루어져 있습니다. `AMD`는 성능 우선, `ARM`은 저발열 효율 우선입니다.

##### ALU

산술 논리 장치라는 실질적인 단위 계산을 담당하는 부품입니다. 간단한 **산술/논리/시프트/비교 연산**만 가능합니다. 저장 및 어려운 작업은 `CPU`와 레지스터 등의 협업을 통해 이루어집니다.

##### 레지스터

가장 작고 빠른 저장 공간으로 각각의 크기가 다른 레지스터들이 역할을 나눠 작업 중인 데이터를 저장합니다.

##### 캐시 메모리(L1, L2, L3)

자주 조회하는 메모리의 데이터를 **지역성/시간성**에 따라 저장해 놓습니다.

##### 클럭

`CPU`의 작업 단위를 맞춰주는 매트로놈 같은 존재로, 1쿨럭 동안 `데이터 이동`, `ALU 연산`, `결과 저장`, `메모리 주소 전송` 등을 할 수 있습니다.

#### 입출력 작업 및 장치

프린터, 네트워크 전송, 디스크 물리 입력과 같은 `CPU`가 주로 처리하지 않는 상대적으로 오래 걸리는 작업을 말합니다. (`CPU`는 요청/제어를 담당합니다.) (해당 지점은 컴퓨터가 느려지는 원인이 되는 주요 원인 중 하나입니다.)

### 소프트웨어

말 그대로 하드웨어가 아닌 것을 말합니다. 대체로 프로그램입니다.

#### 운영체제

컴퓨터 시스템을 관리해주고, 저장 공간, 보안, 입출력 관리 등을 해줍니다.

##### 커널

운영체제의 주요 부품 중 하나로 실질적인 `CPU`, 메모리, 디스크, 입출력 관리를 합니다. 위에서 말한 대부분의 작업은 이미 만들어져 있는 프로그램인 커널에서 이루어집니다. **시스템 호출**을 통해 프로그램이 요청하는 작업을 해주기도 합니다.

##### 쉘

사용자가 커널에 요청하기 위한 명령어 입력 프로그램입니다.

##### 시스템 유틸

기본적으로 내장되어 있는 프로그램으로 `ls`, `cp`처럼 명령어임과 동시에 작업을 처리해주는 프로세스입니다.

#### 링커/로더

로더는 프로그램을 메모리에 적재하고 실행시켜주는 소프트웨어입니다. 또한 필요에 따라 재배치, 할당, 연결을 해줍니다.

링커는 필요한 라이브러리들을 묶어 하나의 실행 파일로 만들어줍니다. 여러 프로그래밍 언어에서 컴파일할 때 링커를 호출합니다.

#### 사용자 프로그램

사용자가 만든 프로그램으로 모든 사용자 프로그램은 커널 위에서 동작합니다. 필요한 하드웨어 자원은 커널에 요청을 통해 실행합니다.

### 펌웨어

하드웨어의 `ROM`에 저장되어 시작 시 항상 즉시 부팅 가능하게 해줍니다.

#### BIOS

`Basic Input/Output System`의 약자로 펌웨어의 일반적인 형태입니다. 컴퓨터를 켰을 때 `CPU`, 메모리, 키보드, 저장 장치 같은 기본 하드웨어가 정상인지 검사 후 하드웨어 초기화, 부팅 장치 탐색, 부트로더를 통해 운영체제를 실행합니다.
