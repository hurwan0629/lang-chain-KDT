# 파이썬의 함수 객체와 callable

## 주제
- 파이썬의 함수는 어떤 구조로 되어있으며 왜 일급 객체로 존재할 수 있는가
- 객체지향 간단 소개
- 파이썬 클래스

### 파이썬 함수의 모습
파이썬의 함수는 일반적으로 선언할 때 `def 함수명(인자):` 형태로 선언합니다.

함수란 특정 값을 주며 호출할 시 설정되어있는 동작을 수행하여 결과를 반환하는 것을 말합니다.

일반적인 함수의 동작은 `호출` > `코드 수행 위치 이동` > `작업` > `돌아오기` 로 이루어집니다. 파이썬은 내부적으로 `def 함수명(인자):`를 읽는 순간 함수에 대한 정보가 담겨있는 객체를 만들게 됩니다.

예를 들어 `def abc()`를 선언하면 `abc`라는 함수 객체가 생성됩니다.

> 파이썬은 **일급 객체**로써 변수로써 동작이 가능합니다. 일급객체는 보통 `변수에 담을 수 있음`, `리스트/딕셔너리 같은 구조에 담을 수 있음`, `함수의 인자로 전달할 수 있음`, `함수가 함수를 반환할 수 있음`을 모두 만족하는 객체를 말합니다.

일반적인 함수 객체에는 아래와 같은 정보들이 존재합니다.
- 이름 (함수명)
- 매개변수 정보 (인자)
- 실행할 코드 (함수 실행 바이트코드)
- 전역 변수 공간참조 (함수 내부에서 쓰이는 전역 변수)
- 기본값 정보 (인자의 기본값. 없으면 None)
- 함수 전용 `__dict__`
- 어노테이션 정보 (메서드 시그니처 힌트. 필수 아님)
- 함수 설명 (개발자가 작성한 글)

등이 있습니다.

#### 클로저 정보
**위에서 설명하지 않은 두 속성이 추가로 존재합니다.**
- (중요) 클로저에서 쓰이는 **`cell variable`**: 내(함수)의 지역 변수인데 내부 함수에서 쓰이기 때문에 버리지 못하는 지역변수. 함수 객체의 속성인 `outer.__code__.co_cellvars` 안에 존재합니다.
- (중요) 클로저에서 쓰이는 **`free variable`**: 내(함수)의 지역변수는 아니고 바깥에서 가져온 지역변수. 함수 객체의 속성중 하나인 `inner.__code__.co_freevars에` 안에 존재합니다.

가 있는데, 예를 들어
```python
# GPT표 예시 코드
def outer():
    x = 10

    def inner():
        return x

    return inner
```
에서 `x`는 `outer`의 `cell variable`이며 `inner`의 `free variable`입니다. 변수 `x`는 자신을 참조하는 값이 모두 사라질 때 `GC`에 의해 정리되게 됩니다.

> 이는 함수를 변수로써 사용할 때 중요한 개념이 됩니다.

### callable `()`
이제 파이썬의 함수는 사실 객체라는 것을 알았는데, 어떻게 함수가 실행 되는 것일까요? 아무래도 `abc()`를 하면 실행이 되는데 `abc`는 그저 객체일 뿐이니 당연하게도 `()`를 통해 실행이 됩니다.

`()`는 `callable`작업을 실행하는 코드로 `CALL` 계열의 동작이 실행되며 함수에서는 `__code__`의 바이트코드를 실행하게 됩니다.

실행 순서는 다음과 같습니다.
1. `abc`라는 이름 찾기
2. `abc`가 가리키는 객체 가져오기
3. 객체가 호출 가능한지 확인
4. 함수 객체라면 안의 `__code__`를 실행할 준비 하기
5. 프레임 만들기
6. 매개변수/지역변수 공간 준비하기
7. `__code__`의 바이트코드 실행하기
8. `return`값 돌려주기
<br><br>

프레임이란 무엇일까요?

**프레임**은 함수객체가 호출될 때마다 만들어지는 새로운 실행용 공간을 말합니다. 프레임은 스택에 존재하며
- 함수의 지역변수
- 실행 위치
등을 내부적으로 가지고 있으며, 작업이 끝나면 해당 공간을 정리하게 됩니다.

# 함수 객체를 이용한 여러 기믹
*기믹이라고 하기에는 널리 사용되지만 새로 배우는 입장에서 `기믹`이라고 표현하였습니다.*

우선 앞서 `()`를 통해 실행이 가능한 것은 함수 뿐만이 아닌 `callable` 값들이라고 말하였었습니다. 그리고 그러한 값들은 아래와 같습니다.
- callback (사실 이건 함수가 될 수도 있습니다.)
- lambda (`lambda [인자]: [간단한 작업]`) (익명함수라고도 불립니다.)
- `__call__()`이 존재하는 클래스들

이렇게 존재하는 `callable`객체는 이제 변수로써 작동이 가능하다는 특성 때문에 다양한 방식으로 재사용과 코드를 효율적으로 쓰게해주는데 쓰입니다.

## callback
앞에서 설명하였듯 사실 `callback` 자체는 `callable`이라기 보다는 작업에 쓰이는 `callable`를 일컫습니다.

예를 들어
```python
def info(var):
  print(f"저는 {var}입니다!")

def exec_for(var):
  for i in range(var):
    print(i)

execute(callback, var):
  print(f"{callback.__name__}를 실행합니다")
  callback(var)
  print(f"{callback.__name__} 종료")

execute(info, "개발자")
execute(exec_for, 10)
```
에서 `callback`와 같이 쓰이며, 이는 앞으로 더 많은 기술로 파생되게 됩니다.

## 고차함수
고차함수는 함수를 인자로 받거나 함수를 반환하는 함수입니다.

1. 함수를 인자로 주는 경우
```python
def apply(func, value):
    return func(value)

def square(x):
    return x * x

print(apply(square, 5))  
# 25
```

2. 함수를 인자로 반환 경우

```python
def func_factory(v: int):
  prefix = "start: " # 클로저의 cell variable에 저장
  def string_builder(s: str) -> str:
    return prefix + s*v # prefix를 free variable에 저장
  return string_builder

a = func_factory(10)
b = func_factory(20)

print(a("h"))
# start: hhhhhhhhhh
print(b("i"))
# start: iiiiiiiiiiiiiiiiiiii
```

이렇게 더욱 흥미로운 작업을 할 수 있게 됩니다. (이 과정에 클로저가 쓰입니다.)

## decorator
데코레이터는 참 하고싶은말이 많은데 딱 보자마자 *얘는 프록시하고 똑같이 생겼네*라고 생각이 들었습니다.

보통 아래와 같이 사용합니다.
```python
def deco(func):
    def wrapper():
        print("함수 실행 전")
        func()
        print("함수 실행 후")
    return wrapper

@deco
def hello():
    print("hello")

hello()
```

## 마무리
이렇게 함수객체에 대해 알아보았습니다.

이전 스프링(부트/프레임워크) 프로젝트에서는 보통 싱글톤/팩토리 패턴을 주로 사용하였었는데, 이번에 함수 객체를 배우면서 뭔가 정리만 해봤던 **전략 패턴**, **어댑터 패턴** 등을 한번 써볼까 라는 욕구가 계속 올라오는 기분이였습니다.

자바에서는 메서드 위주로 작업을 하였었기 때문에 이번에 익숙한 **객체**와 오랜만에 보는 **함수**의 조합은 꽤나 신선하게 다가왔었습니다.

사실 클래스에 대해서도 같이 포스팅을 하려 하였었는데 생각보다 함수에 대한 분량이 많아지는 바람에 다음번에 작성하게 되었습니다.
