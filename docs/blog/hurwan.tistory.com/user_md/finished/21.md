# 메모리에 대한 이해
이번에 C의 포인터 및 특징 등을 이해할 겸, 기존에 알던 메모리 영역에 관한 지식을 좀 확실하게 정리해두려 합니다.

## 메모리의 형태
일단 `C`에 대해서 알아보기 전에, 메모리 영역에 대해 먼저 알아보려 합니다.

일반적으로 운영체제에서 할당해준다고 하는, 메모리를 말하는 것은 RAM을 말합니다.

메모리는 

스택, 유휴공간, 힙, bss, 데이터, 코드 영역으로 나뉘어져 있습니다.

이중에서 스택은 자동으로 프로그램이 쌓아뒀다가, LIFO방식으로 정리해가는 방식으로 관리하는 데이터 영역으로, 함수 호출 순서, 지역 변수, 리턴 주소 등이 일정 생명 주기동안 생성되었다가 사라집니다.

반대로 힙의 경우에는 개발자가 필요에 따라 할당받도록 프로그래밍을 하여 일정한 양의 공간을 받아서 사용 후, 반납하는 (Java, Python의 경우에는 자동으로 정리되는) 공간입니다. 일반적으로 힙에는 개발자가 직접 메모리 주소를 통해 접근하게 됩니다. (변수로 저장해놓을 수 있습니다.)

bss와 데이터 영역은 모두 전역/정적 객체가 저장되는 공간으로, 모두 프로그램 전체동안 살아있어야 한다는 공통점이 존재합니다. 차이점은 bss에는 초기화되지 않았거나 0인 데이터들을 모아두어 프로그램의 런타임에 0을 넣어줌으로써 공간을 절약하기 위한 공간입니다.

코드 영역은 어렵지 않고 C 기준으로 컴파일된 코드가 저장되는 영역입니다. 이는 읽기 전용으로 존재하게 됩니다. (그냥 프로그램 실행 코드라고 이해 가능합니다.)

## C에서의 메모리 관리 방법

C에서는 메서드나 객체라는 개념이 없고 함수와 구조체라는 개념만이 존재합니다. C의 특징이라고 한다면 고급 언어중 가장 로우레벨에 속하며, 포인터라는 주소 참조 기능을 통해 주소를 통해 객체에 직접 접근이 가능합니다.

예를 들어 `int *p;`는 `int`형 변수의 주소를 가리키는 포인터 변수인 `p`를 만들어주며, `p`를 찍으면 `p`에 할당한 변수의 주소가 찍히고, 주소를 통해 값을 꺼내기 위해서는 `*p`를 통해 출력이 가능합니다. 이는 함수에서 객체를 인자 또는 반환값으로 삼는데도 자주 쓰이며, 구조체가 상위 언어의 객체와같이 동작 가능하게 해주기도 합니다.

메모리의 주소 할당의 경우에는 `malloc(받을 메모리 크기)`라는 원하는 메모리의 `n바이트`크기를 할당받는 함수를 통해 실현할 수 있으며, `malloc()`의 반환값은 만든 공간의 힙 메모리의 시작 주소입니다.

이때, 프로그램은 특정 주소에 할당된 공간의 크기를 알 수 있는데 이는 `공간의 메타데이터 | 공간의 시작 주소 .... [끝]`와 같이 메모리 공간이 이루어지기 때문입니다. (하지만 개발자가 직접 뜯어보기는 어렵습니다.)

`int *p = malloc(sizeof(int))`를 통해 받은 힙 메모리의 반납은 `free(p)`를 통해 구현하며, 이때 일반적으로는 괜찮지만 혹시 모를 예외사항을 피하기 위해 `p = NULL`을 통해 이후의 문제 상황을 차단하기도 합니다.

> 추가적으로 메모리(`memory allocate`) 공간을 할당해주는 `malloc()`이외에도 공간을 다시 `0`으로 초기화해주는 `calloc()`와 기존의 데이터에서 쓰지 않는 공간 또는 부족한 공간을 재할당 받기 위한 `realloc()` 또한 존재합니다.

아래는 이해를 돕기 위한 테스트 코드입니다.
```C
#include <stdio.h>
#include <stdlib.h>

// 메모리 영역에 대한 정리
// 메모리의 형태
/* * * * * * * * * * * * 
[stack] - 지역 변수, 매개변수, 함수 호출 정보가 저장되는 공간
 ▼ ▼ stack메모리는 필요 시 아래로 확장 ▼ ▼
  [           유휴 공간 존재           ]
 ▲ ▲ heap메모리는 필요 시 위쪽으로 확장 ▲ ▲ 
[heap] - 동적으로 할당되는 변수나 객체가 저장됨
[bss] - 초기화되지 않은 전역 변수 및 정적 변수. 
        └ 초기화되어도 위치가 바뀌지 않음. 런타임 시점에 메모리 할당 후 0으로 채워 초기화
[data] - 초기화된 전역 변수 및 정적 변수
[code] - 프로그램의 실행 명령이 저장되는 읽기 전용 공간
* * * * * * * * * * * * */

// bss 영역으로 이동
int varBss1;
int varBss2 = 0;

// data 영역으로 이동
int a = 1;

// 현재 파일에서만 접근 가능한 변수로 이동 (/data)
static int varBss3 = 10;

int* counter() {
  printf("\n --- counter() --- \n");
  // bss 영역에 존재
  static int count = 0;

  printf("counter().count++ = %d\n", count++);
  // stack로 anchor 생성
  int anchor = 10;
  printf("counter().anchor = %d\n", anchor);
  printf("counter().anchor addr = %p\n", &anchor);
  
  return &anchor;
}

int* getIntArray(int size) {
  int* arr = malloc(sizeof(int) * size); // 4 * size

  return arr;
}

int main() {
  for(int i=0;i<10;i++){
    int *anchor = counter();
    printf("anchor addr: %p\n", anchor);
    // printf("anchor: %d\n", *anchor);

    printf("\n --- counter() return anchor --- \n");
  }

  int size = 10;
  int* arr = getIntArray(size);
  for(int i=0;i<size;i++) {
    *(arr + i) = i*10;
  }

  for(int i=0;i<size;i++) {
    printf("%d ", arr[i]);
  }
  printf("\n");

  free(arr);
  // printf("after free(arr); arr = %p", arr);
  arr = NULL;
  printf("after arr = NULL; arr = %p", arr);
  return 0;
}
```
