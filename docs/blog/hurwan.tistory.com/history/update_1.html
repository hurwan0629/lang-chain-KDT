파이썬의 실행 방식

파이썬의 대표적인 확장자는 .py입니다.

이를 파이썬 프로그램의 대표 Python 구현체인 CPython이 코드를 읽고 문법 분석 후, 해석하여 바이트 코드로 변환시킵니다.

CPython이란?

CPython은 여러 역할을 담당합니다.

- 파이썬 코드를 바이트코드(.pyc캐싱이 생길 수 있음)로 해석 (컴파일)

- PVM(Python Virtual Machine)을 통해 바이트 코드를 실행 (인터프리팅)

이처럼 파이썬은 보통 인터프리터 실행 방식이라고 하지만 성격이 다를 뿐, 컴파일을 함께 담당하고 있습니다.

타 언어와의 차이

파이썬과 비교되는 대표적인 언어는 C언어 입니다.

C언어는 컴파일 언어로 컴파일러가 기계가 실행 가능한 형태의 파일을 만들어 운영체제가 로드하고 CPU가 실행 가능한 파일을 생성합니다.

하지만 Python은 CPython 엔진 내부의 PVM이 바이트코드를 한 줄씩 해석하여 실행하는 방식입니다.

이처럼 순수 컴파일 방식의 C언어와의 비교가 자주 되는 언어입니다.

파이썬의 다른 얼굴, .ipynb

파이썬의 대표적인 사용처가 연구, 머신러닝 등에 있는 만큼 이를 위한 확장자 또한 마련되어있습니다.

.ipynb는 셀 단위로 메모 또는 파이썬 코드를 작성 가능한 형태의 파일 확장자입니다.

ipynb는 파이썬 파이썬 코드처럼 보이지만 실제로는 json 형태의 코드, 메타데이터, 실행 결과, 노트 등의 정보를 담은 파일입니다.

.ipynb와 .py는 실행 방식의 차이가 존재합니다.

.py의 경우에는

.py코드 > CPython > 문법 분석 > 바이트 코드 컴파일 > PVM 실행 (인터프리팅)

순서였지만

.ipynb는

Jupyter 화면 > PythonKernel > CPython > 문법 분석 > 바이트 코드 컴파일 > PVM 실행 (인터프리팅)

을 셀 단위로 작업하는 방식을 가졌습니다.

이때 유의해야할 점은 .ipynb는 셀이 순서대로 실행되는 방식이 아닌 각기 개별의 실행 단위이며, 결과는 기록하지만 다른 환경에서는 변수의 값을 저장하지 않는다는 점 입니다.

예를 들어

1번 셀

x=1
print(f"x={x}")

2번 셀

print(x)

를 놓았을 때

A컴퓨터에서 1번 셀을 실행하고 저장하면, 1번 셀의 output에는 x=1이라는 과거 실행 결과가 남을 수 있습니다. 하지만 B컴퓨터에서 노트북을 새로 열고 2번 셀만 실행하면, 현재 커널 메모리에는 x가 없기 때문에 NameError가 발생합니다.
