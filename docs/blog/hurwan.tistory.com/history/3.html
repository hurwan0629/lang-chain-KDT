바이트코드를 직접 확인해보기

파이썬 코드는 우리가 작성한 문자열 그대로 실행되는 것처럼 보이지만, 내부적으로는 먼저 코드 객체로 컴파일되고 그 안에 바이트코드, 상수 테이블, 이름 테이블 같은 정보가 만들어집니다.

이번에는 dis 라이브러리를 사용해서 간단한 파이썬 코드가 어떤 명령어들로 나뉘어 실행되는지 확인해보았습니다.

In: 코드

import dis

code = """
x = 10
y = x + 20
print(y)
"""
# compile(source, filename, mode)
# exec는 복수의 문장
compiled = compile(code, "<string>", "exec")
dis.dis(compiled)
print(compiled.co_code)   # 바이트코드
print(compiled.co_consts) # 상수테이블
print(compiled.co_names)  # 네임테이블

dis.dis(compiled)는 바이트코드를 사람이 읽기 좋은 형태로 풀어 보여줍니다. compiled.co_code는 실제 바이트열이고, co_consts와 co_names는 바이트코드가 참조하는 상수와 이름 목록입니다.

compile()과 코드 객체

compile(source, filename, mode)는 파이썬 소스 코드를 코드 객체로 바꾸는 함수입니다.

여기서 source는 실행할 코드 문자열이고, filename은 에러 메시지나 디버깅에서 표시될 이름입니다.

마지막 mode에는 exec, eval, single 같은 값이 들어갈 수 있습니다.

이번 예시처럼 여러 줄의 문장으로 구성된 코드는 코드 객체로 컴파일한 뒤, 그 결과물을 dis로 풀어서 내부 명령어 흐름을 확인할 수 있습니다.

명령어 출력은 어떻게 읽을까?

dis 결과는 처음 보면 숫자가 많아서 헷갈리지만, 한 줄만 떼어놓고 보면 다음처럼 읽을 수 있습니다.

출력 예시

2           2 LOAD_CONST               0 (10)
첫번째 값 원본 코드 줄 번호
두번째 값 bytecode 명령어 위치
세번째 값 명령어 이름
네번째 값 명령어 인자 번호
다섯번째 값 사람이 보기 좋게 해석한 값

예를 들어 LOAD_CONST 0 (10)에서 0은 상수 테이블의 0번 값을 뜻하고, 사람이 보기 좋게 해석하면 그 값은 10입니다.

중요한 점은 0, 1, 2 같은 숫자가 무조건 실제 값 자체를 뜻하는 것이 아니라, 대체로 테이블 안에서 몇 번째 값을 참조하는지 나타내는 번호라는 점입니다.

상수테이블과 네임테이블

코드 객체 안에는 여러 정보가 들어있습니다.

그중 이번 코드에서 눈으로 확인하기 좋은 것은 co_code, co_consts, co_names입니다.

co_code

co_code는 실제 바이트코드 명령어들이 들어있는 바이트열입니다.

다만 사람이 바로 읽기 좋은 형태는 아니기 때문에 보통은 dis.dis()를 통해 명령어 이름으로 변환해서 확인합니다.

co_consts

co_consts는 코드에서 사용된 상수 목록입니다.

이번 코드에서는 10, 20, None이 들어갑니다.

compiled.co_consts
# (10, 20, None)

co_names

co_names는 코드에서 등장하는 이름 목록입니다.

이번 코드에서는 x, y, print가 들어갑니다.

compiled.co_names
# ('x', 'y', 'print')
co_consts와 co_names는 실행하면서 계속 늘어나는 공간이라기보다는, 컴파일 시점에 코드 객체 안에 준비된 참조 목록에 가깝습니다. 실제 변수 값 연결은 실행 중 네임스페이스에서 이루어집니다.

실행 흐름

이번 코드를 바이트코드 기준으로 따라가면 다음과 같은 흐름으로 볼 수 있습니다.

실행 흐름 정리

0. RESUME: 최초 실행 또는 재개 내부 명령어
2. x = 10
- LOAD_CONST: 실행 스택에 10 올리기 
- STORE_NAME: 스택에서 값을 꺼내서 이름 x에 연결함 -> 현재 namespace에 x -> 10 연결

3. y = x + 20
- LOAD_NAME: x가 가리키는 값 10을 스택에 올림
- LOAD_CONST: 20을 실행 스택에 올리기
- BINARY_OP: 이진 계산 실행 (30을 스택에 올림)
- STORE_NAME: 30을 꺼내 y에 바인딩하기

4. print(y)
- PUSH_NULL: 함수 호출을 위한 내부 준비값
- LOAD_NAME: print함수 객체를 스택에 올림
- LOAD_NAME: y가 가리키는 값 30을 스택에 올림
- CALL 1: 인자 1개로 print(30) 호출
- POP_TOP: print가 반환한 None을 버림
- RETURN_CONST: 코드 블록 전체가 None을 반환하고 종료

메모리에는 무엇이 올라가 있을까?

상수 테이블, 네임 테이블, 바이트코드는 모두 Python 프로세스의 메모리 안에 존재합니다.

다만 이들을 실제 실행 스택이나 변수 저장 공간과 완전히 같은 것으로 보면 헷갈릴 수 있습니다.

구분해서 보기

- co_code: 실행할 바이트코드 명령어 목록

- co_consts: 코드에서 참조하는 상수 목록

- co_names: 코드에서 참조하는 이름 목록

- 실행 스택: 명령어가 계산 중 임시로 값을 올려두는 공간

- 네임스페이스: x, y 같은 이름과 실제 객체의 연결을 저장하는 매핑 구조

바이트코드 > 테이블 번호 참조 > 스택에서 계산 > 네임스페이스에 바인딩

정리

이번 예시를 통해 파이썬 코드가 단순히 위에서 아래로 실행되는 것처럼 보이지만, 내부적으로는 바이트코드 명령어 단위로 쪼개져 실행된다는 점을 확인할 수 있었습니다.

x = 10은 상수 10을 스택에 올린 뒤 x에 연결하는 흐름입니다.

y = x + 20은 x의 값과 상수 20을 스택에 올리고, 더한 결과를 y에 연결하는 흐름입니다.

print(y)는 print 함수와 인자 y의 값을 준비한 뒤, 함수 호출 결과를 버리고 코드 블록을 종료하는 흐름입니다.

결국 핵심은 코드 객체 안의 테이블을 참조하고, 실행 스택에서 계산하고, 네임스페이스에 이름과 객체를 연결한다는 흐름입니다.
