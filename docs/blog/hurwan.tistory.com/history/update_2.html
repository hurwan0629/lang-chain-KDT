변수란 무엇일까?

변수는 프로그램에서 데이터를 저장하기 위해 사용하는 이름입니다.

조금 더 정확하게 말하면, 변수는 값을 직접 담는 상자라기보다는 메모리에 만들어진 객체를 참조하는 이름에 가깝습니다.

값을 직접 다루는 대신 변수 이름을 통해 데이터를 읽고 변경할 수 있으며, 프로그램 실행 중에 다른 값을 가리키도록 바뀔 수 있습니다.

변수를 사용하는 이유

변수를 사용하면 데이터를 매번 직접 작성하지 않고 이름으로 다시 사용할 수 있습니다.

즉, 변수는 데이터를 효율적으로 관리하고 재사용하기 위해 필요한 기본 도구입니다.

값 생성 > 객체 저장 > 변수 이름이 참조 > 필요할 때 재사용

문자열 변수의 값 변경

먼저 문자열을 변수에 넣고, 이후 다른 문자열로 바꾸는 예시입니다.

In: 코드

a = "memory"
print(f"a: {a}")
print(f"type of a: {type(a)}")
print(f"memory_id: {id(a)}")

a = "hello"
print()
print("a -> hello")

print(f"a: {a}")
print(f"type of a: {type(a)}")
print(f"memory_id: {id(a)}")

# str 타입은 불변 객체라서 id가 바뀔 수 있습니다.

Out: 출력 예시

a: memory
type of a: <class 'str'>
memory_id: 2503423516784

a -> hello
a: hello
type of a: <class 'str'>
memory_id: 2503422366064
여기에서 중요한 점은 a라는 변수 이름이 바뀐 것이 아니라, a가 바라보는 객체가 바뀌었다는 점입니다.

문자열은 대표적인 불변 객체입니다.

따라서 a = "hello"처럼 새 값을 대입하면 기존 문자열 객체의 내부 값이 바뀌는 것이 아니라, 새로운 문자열 객체를 만들고 변수 a가 그 객체를 다시 가리키게 됩니다.

정수 변수의 값 변경

정수도 문자열과 마찬가지로 불변 객체입니다.

In: 코드

a = 1
print(f"a: {a}")
print(f"type of a: {type(a)}")
print(f"memory_id: {id(a)}")

a = 2
print("a -> int(2)")

print(f"a: {a}")
print(f"type of a: {type(a)}")
print(f"memory_id: {id(a)}")

Out: 출력 예시

a: 1
type of a: <class 'int'>
memory_id: 140712299940280

a -> int(2)
a: 2
type of a: <class 'int'>
memory_id: 140712299940312

a = 1을 실행하면 1이라는 정수 객체가 만들어지고, 변수 a는 그 객체를 참조합니다.

이후 a = 2를 실행하면 1 객체가 2로 수정되는 것이 아닙니다.

새로운 2 객체를 참조하도록 변수 a의 연결이 바뀌는 방식입니다.

사용자 클래스 객체의 값 변경

이번에는 직접 만든 클래스 객체를 사용해 보았습니다.

In: 코드

class ExampleClass():
    def __init__(self, name: str):
        print(f"class init. name: {name}")
        self.name = name
    
    def setName(self, name: str):
       self.name = name
    
    def getName(self):
       return self.name

a = ExampleClass("a")
print(f"id(a): {a}")

a.setName("apple")
print(a.getName())
print(f"id(a): {a}")

Out: 출력 예시

class init. name: a
id(a): <__main__.ExampleClass object at 0x00000246DE808770>
apple
id(a): <__main__.ExampleClass object at 0x00000246DE808770>

이 예시에서는 객체의 주소가 그대로 유지됩니다.

왜냐하면 a가 다른 객체를 새로 가리킨 것이 아니라, 기존 객체 내부의 name 필드 값만 바뀌었기 때문입니다.

즉, 변수 a가 바라보는 객체 자체는 그대로이고, 그 객체 안의 상태만 변경된 것입니다.

a > ExampleClass 객체 > name: "a" > name: "apple"

파이썬과 CPython의 메모리 관리

앞선 예시에서 문자열과 정수는 값을 바꾸었을 때 다른 객체를 참조하는 모습을 보였습니다.

반면 사용자 클래스 객체는 같은 객체 내부의 값이 바뀌었기 때문에 객체 주소가 유지되었습니다.

이 흐름을 이해하려면 프로그램에서 자주 언급되는 메모리 영역을 간단히 정리할 필요가 있습니다.

대표적인 메모리 영역

- 힙: 실행 중 동적으로 만들어지는 객체와 데이터가 저장되는 공간

- 스택: 함수 호출 정보, 인자, 지역 변수 참조 등이 관리되는 공간

- 데이터 영역: 전역 변수나 static처럼 프로그램 시작부터 끝까지 유지되는 값이 저장되는 공간

- 코드 영역: 실행할 코드, 명령어, 함수 코드 등이 존재하는 공간

파이썬에서는 우리가 다루는 값들이 대부분 객체로 관리됩니다. 그래서 변수 이름 자체와 그 이름이 참조하는 객체를 구분해서 보는 것이 중요합니다.

불변 객체란?

불변 객체는 한 번 만들어진 뒤 내부 값을 직접 바꿀 수 없는 객체입니다.

대표적으로 int, str, tuple 같은 자료형이 있습니다.

예를 들어 a = 1이라고 작성하면 1이라는 객체가 만들어지고, 변수 a는 그 객체를 가리킵니다.

이후 a = 2를 실행하면 1 객체의 값이 바뀌는 것이 아니라, 2 객체가 준비되고 변수 a가 다시 그 객체를 가리키게 됩니다.

a = 1 > a가 1 객체 참조 > a = 2 > a가 2 객체 참조

반대로 사용자 클래스 객체처럼 내부 상태를 바꿀 수 있는 객체는 같은 객체를 유지한 채 속성 값만 바뀔 수 있습니다.

그래서 ExampleClass 예시에서는 name 값이 "a"에서 "apple"로 바뀌어도 객체의 주소는 그대로 유지되었습니다.

변수 이름은 어디에 저장될까?

파이썬에서 변수 이름은 네임스페이스(namespace)라는 공간에서 관리됩니다.

네임스페이스는 쉽게 말해 {이름: 객체} 형태의 매핑 구조라고 볼 수 있습니다.

그래서 a = 1을 실행하면 대략적으로는 1 객체가 만들어지고, 현재 네임스페이스에 a라는 이름이 그 객체를 가리키도록 등록됩니다.

개념적으로 보면

a = 1

# 대략적인 이미지
namespace = {
    "a": 1 객체의 참조
}

이때 객체 자체에는 타입 정보, 참조 횟수 같은 메타데이터가 함께 관리됩니다.

즉, a라는 이름은 네임스페이스 쪽에서 관리되고, 1 객체는 객체 나름대로 타입과 값에 대한 정보를 가지고 있다고 이해하면 됩니다.

globals()로 네임스페이스 확인하기

globals()는 현재 실행 중인 모듈의 전역 네임스페이스를 나타내는 딕셔너리를 반환하는 내장 함수입니다.

이 딕셔너리를 통해 전역 범위에 정의된 변수, 함수, 클래스 이름과 실제 객체 간의 연결을 확인할 수 있습니다.

In: 코드

from pprint import pprint

# pprint(globals())
print(globals().keys())
pprint(globals()["__name__"])

Out: 출력 예시

dict_keys(['__name__', '__doc__', '__package__', '__loader__', '__spec__',
'__builtin__', '__builtins__', '_ih', '_oh', '_dh', 'In', 'Out',
'get_ipython', 'exit', 'quit', 'open', '_', '__', '___',
'__vsc_ipynb_file__', '_i', '_ii', '_iii', '_i1', 'np', 'nd',
'a', 'ExampleClass', 'pprint'])
'__main__'

globals() 주요 키 정리

- 사용자 변수/함수/클래스: 내가 직접 만든 이름들

- __name__: 현재 실행 환경의 이름

- __builtins__: print, len, int 같은 기본 내장 기능 모음

- In: 실행한 입력 코드 목록

- Out: 출력 결과 목록

- _: 직전 출력값

- _i: 직전 입력 코드

- get_ipython: Jupyter/IPython 환경 제어 함수

- exit, quit: 실행 환경 종료용 객체

- open: 파일 열기 함수

globals()를 보면 파이썬에서 변수 이름이 단순히 눈에 보이는 글자가 아니라, 실제로는 네임스페이스라는 딕셔너리 구조 안에서 객체와 연결되어 관리된다는 점을 확인할 수 있습니다.

정리

파이썬에서 변수는 값을 직접 담는 상자라기보다 객체를 가리키는 이름에 가깝습니다.

불변 객체인 int, str은 값을 바꿀 때 기존 객체를 수정하는 것이 아니라 새 객체를 참조하는 방식으로 동작합니다.

반면 사용자 클래스 객체처럼 내부 상태를 바꿀 수 있는 객체는 같은 객체를 유지한 채 속성 값만 변경될 수 있습니다.

마지막으로 globals()를 통해 현재 전역 네임스페이스를 확인하면, 변수 이름과 객체가 어떤 식으로 연결되어 있는지 조금 더 구체적으로 이해할 수 있습니다.
