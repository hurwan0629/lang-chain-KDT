코사인 유사도 풀이 보기 
코사인 유사도는 두 벡터의 방향이 얼마나 비슷한지.

[코사인 유사도] = [A]·[B] / ([|A|] x [|B|])

[두 벡터의 내적] / [두 벡터 크기의 곱]

- -1일수록 방향이 완전히 다른 것이고
- 1일수록 완전히 같은 방향입니다.

문제 1
A = [1, 0]
B = [0, 1]

코사인 유사도는?

벡터 내적 = 0
분모 구할 필요 없음.

> 0

문제 2
A = [1, 2]
B = [2, 4]

코사인 유사도는?

벡터 내적 = 10
분모: 루트 5 곱하기 루트 20 = 2루트5 * 루트5 = 10

따라서 1

행렬곱 풀이 보기
