# 90 Uncertain

자동 분류만으로 출처나 주제를 확정하기 어려운 파일을 모아둔 영역입니다.

## Folders

- `python_remaining/`: 기존 `workspace/python/`에서 명확히 분류하지 않은 잔여 폴더
- `personal_remaining/`: 기존 `workspace/personal/`에서 명확히 분류하지 않은 잔여 폴더
- `personal_dummy/`: 임시 메모 또는 실험성 자료
- `personal_new_folder/`: 이름만으로 목적을 판단하기 어려운 폴더

## Rule

여기 있는 파일은 버린 파일이 아니라 수동 검토 대기 파일입니다.
