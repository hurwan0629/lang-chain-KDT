해당 프로젝트에 cv가 있을 줄 알았는데 존재하지 않습니다.

우선 이미지의 경우에는 `./datas` 에 `n-fingers/` 형태로 16장씩 넣어두었고 4장을 val로 분리해야할 필요가 있습니다.

그리고 학습 데이터가 12개밖에 없기 때문에 최대한 겹치는 사진이 없게 데이터를 구성할 필요가 있습니다.

cnn을 이용한 모델을 만드는 것으로 파악이 됩니다. 
`.py` 프로젝트를 만들고 싶지만 문제 조건은 `.ipynb` 입니다.

우선 순서를 생각해보면 
1. 일단 ImageFolder 클래스를 이용해서 데이터셋을 불러올 필요가 있습니다. 
2. 이미지 폴더를 정리한 후 픽셀 통계를 내어야 합니다. 이미지는 jpg 형태이기 때문에 RGB 형태로 matplotlib 1열 3행 형태로 출력하면 될 것 같으며 학습 이미지만 사용하므로 `train/` 데이터셋만 사용하면 될 것 같습니다. 평균/표준편차를 구하고, 이것은 numpy로 구현하면 될 것 같습니다. 검증 이미지에도 이 값을 적용하라는건 아마 transform를 이야기하는 것 같습니다.
3. 그리고 세번째 셀에서는 모델을 만들 면 될 것 같은데 파라미터수가 5만개 이하라고 하니 일단 찍어보면서 조절해보면 될 것 같습니다. 그리고 Conv2d가 2개이며 마지막에 분류 FC 레이어를 이용하여 classifier head를 붙이면 되는 형태일 것 같습니다.

딱히 옵티마이저 및 손실함수 이야기는 없으니 손실함수는 자연스러운 Cross-Entropy 방식으로 가고 옵티마이저는 데이터가 적으니 AdamW 방식으로 가겠습니다.
