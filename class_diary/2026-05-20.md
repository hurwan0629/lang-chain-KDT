# 파이썬으로 시작하기.

파이썬의 특징은 다음과 같다.
## 장점
- 간결함 → 빠른 개발 → 높은 생산성
- 사람의 언어와 비슷한 형태를 가짐
- 인터프리터(한줄씩 해석해서 읽는 방식)를 사용한다.
- 데이터 관련 라이브러리 생태계가 넓음 → 라이브러리를 통해 남이 만든 **검증된** 유용한 기능을 꽁으로 쓸 수 있음
- 웹, 데이터, 인공지능, 자동화, 스케줄링 등이 가능함

<br><br>

## 단점
- 기계에 최적화 된 코드 형태가 아니여서 C, Assembly에 비해 실행 속도가 낮을 수 있다.

## IT계열의 취업

어느 직군이든 신입이 어렵다고 하지만 선생님은 IT 직군이 그나마 낫다고 하신다.

인문계열은 학벌이나 레벨을 많이 보는데 이공계열에서는 학벌/성별 등을 보지 않고 실력을 더 많이 보기 때문에 유리한 면이 있다고 하신다.

경력이 우대받는 것은 사실이지만 IT는 경력이 우대받는 갭이 훨씬 크다.

### 왜일까?
경력직의 경우에는 **포폴이 괜찮은 사람**을 말한다. 이는 개발의 경우에는 경쟁이 매우 심하며 실무 경험에 따라 개발 속도가 매우 달라지기 때문이다.

예를 들어 A사와 B사에서 팀의 구성에 따라 경쟁 구도가 완전히 달라질 수 있기 때문이다.

**반대로 말하면 경력과 포폴이 좀 쌓이다 보면 깡패가 될 수 있다. (잘하는 개발자면)**

### OS란? - Operating System
컴퓨터, 냉장고 등등처럼 장치를 다루며 운영해주는 시스템을 말하며, <br>
본인(허완)은 **사용자와 프로그램이 컴퓨터(기기)를 다룰 수 있게 해주는 하드웨어 바로 위에 존재하는 소프트웨어** 라고 생각한다.


# 프로그래밍 언어에서 힘든점
요즘에는 LLM이 워낙 잘 찾아주지만 과거에는 지금보다 훨씬 에러를 찾는 능력이 중요했다.

과거에는 구글이 AI가 없음에 따라 더욱 강력한 도구였는데 공부를 하거나 에러를 찾을 때 많이 쓰였다. (그 때에는 Swift, Go 같은 코딩 용어의 동의어가 많아서 프로그래머들이 문제를 찾는데 시간이 걸리곤 했다. 현재는 AI 덕분에 이런 문제가 다수 해결되었다.)

## AI에 관하여
AI는 학습된 데이터에 기반해서만 도움을 주기 때문에 비즈니스 환경(특히 보험, 금융 등)에서는 LLM의 사용이 제한될 수 있기 때문에 스스로 해결하는 능력을 기를 수 있어야한다.

# 파일의 형태
파이썬은 보통 2개의 파일 형태를 가지고 있는데
- `.py`: 파이썬으로 작성된 일반적인 소스코드입니다. 순차적으로 실행되며 **완성된 프로그램**을 만들 대 사용하게 됩니다. **함수**, **클래스** 등을 통해 **구조와 유지보수에 유리합니다**.

- `.ipynb`: `Jupyter Notebook`형식의 파일로, 코드를 셀들로 나뉘어져 노트 및 연구를 하기 위한 파일입니다. **데이터분석, 머신러닝 실험, 시각화, 교육, 강의 자료 작성 등에 쓰입니다**.

*당분간은 노트 필기를 위해 `.ipynb`를 쓰게 될 것이라 합니다.*

# 팁
파이썬을 사용할 때 `venv`라는 가상환경을 사용하면 컴퓨터를 무겁게 하지 않으며 파이썬을 사용할 수 있습니다. 또한 외부에 공유할 때 더욱 편하게 공유 및 사용이 가능합니다.
1. 프로젝트 폴더 파기
2. 프로젝트 폴더 들어가기
3. `python -m venv .venv` 작성 (파이썬 모듈(venv)를 통해 `.venv/`를 만들겠다.)
4. 폴더에서 `./venv/Script/Activate.ps1` 를 실행하기(윈도우 기준. mac는 알맞는 실행기 실행하기) powershell로 실행.
5. 필요한 라이브러리 `pip install [라이브러리 명]` 입력하기
6. `pip freeze > requirements.txt`로 다른 사람이 같은 라이브러리 사용 가능하게 만들어주기
