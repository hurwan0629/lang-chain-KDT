# 커리큘럼

  - 파이썬을 선택한 이유는 AI를 다루기 편해서

3. 데이터 분석 (머신러닝/딥러닝 기초) (기계를 도메인 지식에 기반해서 효율적으로 사용하는 방법)
4. 자연어 처리/컴퓨터 비전 (NLP란? 사람이 하는 언어를 읽고, 이해하며 읽을 수 있게 하는것) (컴퓨터 비전은 사람이 본것을 보고, 이해하고, 표현할 수 있게 하는 것) (다른 개념이지만 보통 함께 쓰임)
5. 멀티 모달 강화 학습 (기계가 스스로 학습을 하고 스스로 진화하고 강화학습을 하게 하는 것을 설계하는 방법)
6. 랭체인과 랭 그래프 Agent (이번 KDT 이름의 랭체인은 초기 나라에 제출할 때 랭체인이 중요하다 여겨져서 제출을 했던 것인데 요즘에는 랭체인 < 랭그래프 < Agent < 토큰을 적게쓰는 방식 을 중요하게 여긴다. -> 트렌드에 맞게 수업을 진행할 예정)

이때 학사/석사의 차이는 데이터 분석에서 크게 온다

데이터 분석은
1. 어떻게 해야 잘 팔 수 있지? 같은 거에 대해서 마케팅과 같은 분석 및 개선을 하는 연구를 하는 사람 -> 석사생(통계 + ai)들이 많다.
2. 기본적인 데이터 분석은 석사만큼의 필요 없고, GPT가 더 잘함. 
애초에 중요한 자료는 온라인 AI에 넣지 않기 때문에 데이터를 다루는 능력은 일반적인 개발자들이라면 다 할줄 알아야한다.

--> 데이터 분석을 통해 취업을 하는 것은 더욱 강력한 능력과 전문성을 요구한다. (높은 허들과 적은 수요)
