# 페이지 별 존재할 기능들

## 페이지 목록
#### 사용자
- 메인페이지
- 로그인 페이지
- 회원가입 페이지
- 상품 검색 및 목록 페이지
- 상품 조회 및 장바구니담기/결제 페이지
- 장바구니 페이지
- 결제 페이지 (최종 확인 및 결제버튼)
- 결제 완료 페이지
- 마이페이지
- 주문 확인 페이지
- 주문 상세 페이지 (상품 목록)
#### 관리자
- 메인페이지 (로그인)
- 상품 전체 조회 및 검색 페이지
- 상품 상세 페이지 (재고, 이름, 가격, 이미지 관리)
- 주문 조회 페이지 (사용자와 동일한 흐름)
- 주문 상품 페이지
- (보류) 사용자 확인 

## 사용할 기술
- daum 주소 (회원가입 시 1번)
- email 확인 api (brevo 생각중)
- portone 결제 대행
- 배송: 그냥 db 기록 및 N초 대기
- RabbitMQ: 결제(포트원)
