# 벡터와 행렬의 직관적 이해
> 벡터와 행렬이 어떤 것인지 직관적인 이해로 설명하는 글입니다.

## 벡터
일단 벡터를 먼저 짚고 넘어가겠습니다.

벡터는 특정 기저에 존재하는 기저벡터들의 속성을 얼마나 가지고 있는지를 나타냅니다.

예를 들어서 일반적인 고등학교 수학 과정까지 익숙하게 사용하는 `(x, y)` 형태로 나타내는 좌표 또한 실제로 `[1, 0]`, `[0, 1]` 형태의 2개의 기저벡터에 대해 각각 어느정도의 크기를 가지는지를 의미합니다. `[1, 2]`라고 표현했다면 일반적인 2차원 좌표평면에서는 `1 * [1, 0] + 2 * [0, 1] = [1, 2]` 의 형태로 표현이 되게 되는 것입니다.

## 벡터 응용
여기에서 벡터에 대한 조금 더 확장된 이해를 해보면 다음과 같습니다.

예를 들어서 4차원 공간이 다음과 같은 기저벡터를 가진다고 해보겠습니다.
```
P = [
  [1, 0, 0, 0]
  [1, 1, 0, 0]
  [0, 0, 1, 0]
  [1, 0, 1, 1]
]
```

해당 기저에서의 c의 벡터가 `[1, 2, 3, 4]` 라고 한다면 x는 순서대로
- 1만큼의 `[1, 1, 0, 1]`
- 2만큼의 `[0, 1, 0, 0]`
- 3만큼의 `[0, 0, 1, 1]`
- 4만큼의 `[0, 0, 0, 1]`

이는 원벡터(x)로 따지면 `[1, 3, 3, 8]`의 형태를 가지게 됩니다.

이는 반대로 생각하였을 때 원벡터를 행렬을 통한 선형 변환을 했을 때 `[1, 2, 3, 4]` 가 되었다고 볼 수 있습니다.

결론적으로 다음과 같은 수식이 성립되게 됩니다. 

> `x T P^-1 = c`, `x = c T P`

## 선형 변환과 선형성
선형성은 벡터의 변환이 다음과 같은 성질을 만족하는 것을 말합니다.

> `T(x) = T(a*v_1 + b*v_2) = aT(v_1) + bT(v_2)`

이는 위의 **벡터 응용**에서 말한 것과 동일한 방식을 따르며, 원벡터 `x`가 새로운 기저인 `[v_1, v_2]`로 적용되게 된다면 `[v_1, v_2]^-1 T x = c` 의 형태가 되는 것을 나타냅니다.

> 해당 개념은 선형 대수학을 공부하며 머릿속에서 가지고 놀 수 있을 정도의 수준이 된다면 다음 작업들을 할 때 보다 직관적으로 수식 또는 모델을 이해할 수 있게 해줍니다.
