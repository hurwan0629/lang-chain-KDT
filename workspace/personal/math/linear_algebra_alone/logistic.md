# 로지스틱 회귀에 사용되는 여러 수식
> 이번 글에서는 이진/다중 분류의 **로지스틱 회귀** 과정을 따라가며 수식을 함께 살펴보도록 하겠습니다.

## 로지스틱 분류
로지스틱 회귀는 $[-\infty, \infty]$ 값을 $(0, 1)$ 으로 변형해주는 **sigmoid function**을 이용한 양성/음성 판별에 주로 쓰이는 모델입니다. 또한 이를 응용하여 이진 분류 이상의 다중 분류 문제에도 사용될 수 있습니다.

로지스틱 회귀를 이용한 분류는 크게 2가지로 이루어질 수 있습니다.

## 1. 이진분류
먼저 이진분류에 대해서 알아보겠습니다.

이진분류의 큰 흐름은 다음과 같습니다.
1. 회귀를 통한 데이터의 선형 변환
2. 선형 변환된 데이터들에 대한 시그모이드 함수 적용
3. **BCE**(`Binary Cross Entropy`) 를 이용한 가중치의 기울기 계산
4. 가중치 학습

> 이때 회귀를 통해 결과로 나온 `sigmoid function` 적용의 대상이 되는 결과 집합을 `logits`라고 부릅니다.

### 선형 변환
데이터를 선형변환 하는 것은 일반 선형회귀와 동일하게 동작합니다.

$$
z = w^Tx + b
$$

여기에서 나온 $z$에 대한 더이상의 활성화 함수 또는 선형 변환을 하지 않는 경우에는 이것을 **logit**이라고 부르는 **확률화 되기 이전의 원시 점수**집합이 나오게 됩니다.

이진 분류의 경우에는 주로 1개의 데이터를 가진 (열)벡터로 결과가 나오게 됩니다.

### 시그모이드 적용
시그모이드 함수는 다음과 같은 형태를 가진 함수입니다.

$$p = \sigma(z)$$

$$p = \frac{1}{1+e^-z}$$

### BCE 계산
**BCE**는 `Binary Cross Entropy`로 한글로 풀어 설명하면 **이진 분류의 결과에 대한 실제 값과의 교차 불확실성** 정도로 해석이 됩니다. 

**BCE**의 수식에서 실제 값을 $(y = 1\,|\,0)$ 라고 하며 모델이 예측한 점수(시그모이드 적용 후)를 $0<p<1$ 라고 한다면 수식은 다음과 같습니다.

$$L = -[y\operatorname{log}(p) + (1-y)\operatorname{log}(1-p)]$$

여기에서 해당 수식에 익숙하지 않으면 어렵게 느껴질 수 있지만 수식을
- `y가 0일때`: $L = -(1-y)\operatorname{log}(1-p)$
- `y가 1일때`: $L = -y\operatorname{log}(p)$

로 나누어 생각할 수 있습니다. $\operatorname{log}$의 계수는 항상 `1`이라고 생각할 수 있으며 $\operatorname{log}$를 가하는 값은 정답 클래스를 어느정도의 확률 ($0<p<1$)로 예측했나로 이해할 수 있습니다.

> 최종적으로 실제 정답에 대한 확률이 `1`보다 작아질수록 $L$이 늘어나게 됩니다.

### BCE 미분
위에서 최초로 사용했던 $w, b$에 대해 미분을 진행합니다.

이때 미분의 대상은 **BCE** 손실함수로 아래 수식을 미분하게 됩니다.

$$L = -[y\operatorname{log}(p) + (1-y)\operatorname{log}(1-p)]$$

$$
\begin{aligned}
\frac{\partial L}{\partial p} &= -\frac{y}{p} -\frac{1-y}{1-p} \\
&=\frac{p-y}{p(1-p)}
\end{aligned}
$$

이때 $\operatorname{sigmode}$ 함수의 경우에는 식을 미분하면 다음과 같습니다.

$$\frac{\partial}{\partial z} \left(\frac{1}{1+e^-z}\right) = p(1-p)$$

이때 저희가 미분한 $L$은 다음과 같은 과정으로 만들어졌습니다.

```
z → sigmoid → p → BCE → L
```

해당 미분식은 다음과 같습니다.

이를 역으로 올라가면

$$
\frac{\partial L}{\partial p}(Loss 미분) \cdot \frac{\partial p}{\partial z} (sigmoid 미분) = \frac{\partial L}{\partial z} = \frac{p-y}{p(1-p)} \,\cdot\,p(1-p) = p-y
$$

즉 

$$
Loss와\,Sigmoid의\,미분 = p-y
$$

가 됩니다.

예를 들면 실제 정답이 `1`인 경우 모델이 `0.8`로 예측하엿다면 미분값은 `-0.2`가 되어 $-\eta(-0.2)x=0.2\eta x$ 만큼 $w$를 더해주게 됩니다.
