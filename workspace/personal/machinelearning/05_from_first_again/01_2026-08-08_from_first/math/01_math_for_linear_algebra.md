# 선형대수의 기초 문법
머신러닝을 공부하다보면 이런저런 함수와 수식들을 마주치게 됩니다. 가장 대표적으로 행렬곱이 있으며 조금 더 나아가는 경우에는 투영, 점추정, 코사인 유사도, 고유벡터 등을 이용한 가중치 추정 등이 있습니다.

이러한 작업을 하며 몇번 마주치게 된 문제점은 코사인, 사인, 벡터 등과 같은 기본적인 개념을 자유자재로 다루지 못하면 은근히 고생하는 경우가 있습니다.

예를 들면 `cos`는 그냥 특정 각도로 특정 길이만큼의 위치의 `x`값은 무엇인지를 나타내는 값으로 볼 수 있지만 본질적으로는 `어떤 방향과 다른 방향이 얼마나 정렬되어있는지를 나타내는 값`으로도 나타낼 수 있습니다. `cos`를 처음 접하면 보통 좌표평면의 `x`축을 기준으로 잡기 때문에 이런 오류가 발생했던 것 같습니다. 이를 통해 0도는 같은방향, 90도는 직교, 180도는 반대방향과 같은 기준이 만들어지게 됩니다.

## 대수학이란
대수학을 크게 말하면 숫자 자체만 계산하는 것을 넘어서, 문자와 기호를 사용해 관계와 연산 규칙을 다루는 수학이라고 할 수 있습니다. 

예를 들면 `2 + 3 = 5`와 같은 수식을 일반화하여 `ax + b = 0`과 같은 형태로 일반화 하는 것을 말합니다.

그중에서도 선형대수는 벡터, 행렬, 선형 변환을 주로 다루는 분야가 됩니다.

## 벡터
벡터에는 여러 연산이 존재합니다. 두 열 벡터가 있을 경우 두 열 벡터의 동일한 위치의 요소들끼리 곱하여 더하는 것을 내적이라고 합니다. 보통 이를 도트곱이라 하며 다른 표현으로는 `aTb`와 같이 할 수 있습니다. 또한 해당 연산의 결과가 0이 된다면 이를 `Orthogonal Inner Product`라고 부르게 됩니다. (직교내적)

보통 내적은 `행벡터 x 열벡터`의 형태가 됩니다. 하지만 외적곱이라 불리는 `열벡터 x 행벡터`의 경우에는 행렬로 결과가 나오며 `(j, i)`의 위치에는 `v1_j x v2_i`의 결과가 나오게 됩니다.

따라서 행벡터가 앞에있으면 스칼라가 나오고 열벡터가 앞에있으면 행렬이 나오게 됩니다. 행렬곱 또한 이러한 내적의 반복으로 앞부분의 행렬의 한 행벡터에 대해 뒷부분의 행렬에 대해 여러 열들이 순서대로 도트곱(내적)되어 새로운 벡터를 만들어낸다고 볼 수 있습니다.
