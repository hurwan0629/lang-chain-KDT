# 리액트
- UI 를 구성하기 위한 자바스크립트 라이브러리
- 컴포넌트를 기반으로 화면을 효율적으로 재사용/관리할 수 있도록 설계된 프론트엔드기술
- 전통적인 DOM을 직접 조작하는 대신, 가상 DOM(Virtual DOM)을 통해 변경된 부분만 최소 비용으로 업데이트 함
- SPA 개발용
- SPA 개발을 넘어 next.js같은 프레임워크와 함께 SSR/CSR/SSG/ISR 등 다양한 렌더링 전략을 지원하는 기술을 가졌습니다.

SPA (Single Page Application)
- 하나의 HTML 페이지에서 모든 화면 전환을 처리하는 웹 어플리케이션 방식
- 기본 MPA(Multi Page Application)처럼 페이지 이동 때마다 서버에서 HTML을 재요청하지 않고, 처음 한번만 HTML, CSS, JS를 받아오고 이후 화면은 자바스크립트가 브라우저 내부에서 렌더링을 변경해 처리합니다.


리액트의 동작 원리
- 리액트는 UI를 컴포넌트 단위로 구성함. 화면을 버튼 카드, 리스트처럼 작은 단위의 컴포넌트로 쪼개어 만들고, 각 컴포넌트가 자신의 상태와 렌더링 방식을 스스로 관리하도록 함으로 재사용성과 유지보수성을 극대화
- 상태가 바뀌면 새로운 Virtual DOM을 만들고, 이전 Virtual DOM과 비교 후, 이전 렌더링 때 만들어 두었던 Virtual DOM과 어디가 어떻게 달라졌는지 계산
- Hook를 통해 상태관리와 렌더링 사이클을 제어
- 리액트는 크게 `class`를 통해 객체지향으로 작업할 수 있고, `hook`를 통해 함수형 프로그래밍을 할 수 있습니다.

 
Vite (비트)
> 차세대 프론트엔드 개발을 위한 초고속 빌드 도구로 기존 번들 (`Webpack` 등) 보다 빠르게 개발 서버를 실행하고 파일 변경을 처리할 수 있는 도구

`npm create vite@latest [프로젝트명]`
