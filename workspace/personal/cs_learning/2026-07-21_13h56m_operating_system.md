## 파일 시스템
리눅스를 통한 시스템 파악은 작진 않지만 파일로써 관리되기 때문에 객체지향적으로 공부를 하기 좋습니다.

리눅스의 파일시스템은 VFS라는 Virtual File System이라는 인터페이스 구현체가 존재합니다. 그중 대표적인 예시중 하나가 ext입니다.

이러한 파일시스템은 메모리 및 디스크로부터 프로세스의 요청 및 커널의 호출에 따라 저장되어있는 캐시파일 또는 페이지 폴트 시 디스크로부터 데이터를 가져오게 됩니다. 

파일 시스템의 단위는 **블록**으로 이는 페이지 또는 프레임과 별개로 디스크 및 메모리 모두에서 통용 가능한 파일시스템이 데이터를 다루는 최소 단위입니다. 리눅스의 모든것은 파일로써 관리되며 모든 파일과 디렉토리에는 `dentry`라는 VFS객체가 존재하여 이름을 통해 자신의 정보가 저장되어있는 `inode` 번호를 확인할 수 있게 되어있습니다. 

사용자 프로세스가 커널쪽으로 fd와 함께 파일 입출력 작업을 하게 된다면 커널은 해당 프로세스의 `task_struct`에 존재하는 `files_struct`객체에서 `fdtable`를 통해 파일에 접근하게 됩니다. 여기에서 `fdtable`은 프로세스의 `fd`에 대해 할당되어있는 `file struct`를 뽑아 안에 존재하는 여러 메타데이터 (권한, 현재 오프셋, 경로, 마운팅, inode)와 f_op라는 파일 오퍼레이터를 통해 파일을 다룰 수 있게 됩니다.
