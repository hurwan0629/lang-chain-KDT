# [Computer Science]

## 1. 인터럽트
인터럽트는 다음과 같은 하드웨어에서 발생합니다.
- Timer
- Network Card
- Keyboard
- Disk Controller

예를 들어 특정 프로세스가 인터럽트와 아예 관계없는 계산을 하고있어도 Timer 인터럽트가 발생한다면 해당 작업이 수행되게 될 수 있습니다.

이 때문에 인터럽트가 비동기적으로 실행된다 라고 불리게 됩니다. (다른 프로세스가 cpu를 사용할 때에도 언제든지 작업을 수행하다가 작업이 끝남을 알릴 수 있어서)

네트워크 패킷 또한 비슷하게 NIC에 packet 도착 후 Interrupt를 통해 CPU가 네트워크 커널 코드를 실행할 수 있게 해주게 됩니다.

## 2. 예외 - Exception
Exception은 CPU가 명령어를 실행하다가 문제나 특별한 상황을 발견한 경우를 말합니다. 대표적인 예시로는
- `div zero`
- 잘못된 메모리 접근
- `Page Fault`
- `Breakpoint` 

가 존재합니다.

이러한 작업은 진행중인 프로세스에 의해 발생하기 때문에 이를 **동기적**(synchronous)라고 부르게 됩니다.

### 예외의 3가지 종류
`x86` cpu 아키텍처에서는 Exception 또한 성격에 따라 나누게 됩니다.

1. Fault: 도중에 문제를 해결한 후 명령어를 재개 가능한 경우 (예: `Page Fault`)
2. Trap: 명령어가 끝난 뒤 해결 후 다음 명령어부터 진행하는 형태. (예: 디버깅 `breakpoint`) 경우에 따라 Trap를 프로그램이 의도적으로 Kernel로 진입한다는 의미로 사용되기도 합니다. 
3. Abort: 원래 실행으로 복귀하기 

여기에서 예외를 처리하고 다시 프로세스의 실행 위치로 돌아가기 위해 `RIP`에 현재 실행 명령어를 넣으며 `RSP`에 스택 포인터를 넣어주어 이후 다시 실행하게 될 때 커널이 사용하는 `Kernel Stack`를 활용하여 코드를 실행한 후 이전에 실행하던 프로세스의 정보를 불러와 해당 작업을 이어나가줍니다.
