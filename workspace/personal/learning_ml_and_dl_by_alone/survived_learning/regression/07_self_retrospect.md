# 모델 평가 방법
지금까지 `선형 회귀`, `릿지`, `랜덤 포레스트`, `그래디언트 부스트`를 사용해보면서 뭔가 이것저것 알아가긴 했지만 진짜로 데이터를 분석한다기보다는 그냥 모델 함수, 메서드를 사용할 뿐이라는 생각을 하였습니다.

여기에서 알아야겠다 생각한 것은 어떤 모델이 잘나온 모델인지 스스로 평가하고, 튜닝할 수 있는지라고 생각하였습니다.

예를 들어서 이전에는 물론 `MAE`, `RMSE`, `R2-score`를 쓰긴 했지만 아직 명확하다 생각하지 않았습니다.

우선 알던 지식을 설명해보면
- `R2-score`: 결정 계수로 1에서 `(실제값 - 평균)^2`를 `(실제값 - 예측값)^2`로 나눈 것을 뺀 것 입니다. 모델이 전체 변동을 얼마나 설명하는지를 나타냅니다.
- `MAE`: 평균 절대 오차로 `sigma(절댓값(실제값 - 예측값)) / n` 입니다. 평균적으로 얼마나 틀리는지 입니다.
- `MSE`: 평균 제곱 오차로 위의 식에서 절댓값 대신 제곱을 한 방식입니다. 큰 오차를 더 크게 적용하는 방식입니다.
- `RMSE`: `MSE`값에 제곱근을 씌운 값입니다. 실제 단위로 맞춘 방식입니다.
