# 마음가짐

예를 들어서 내가 취업을 한다고 하는데? 내가 할 수 있는일이 뭐가 있냐? 라고 한다면 내가 할 수 있는 대답은?


## 내가 할 수 있는 일
1. 내가 만들 수 있는 것
- 나는 어떤 웹 서비스를 처음부터 끝까지 만들 수 있는가?
> 
- 프론트엔드에서 구현할 수 있는 기능은 무엇인가?
- 백엔드에서 구현할 수 있는 기능은 무엇인가?
- 데이터베이스 설계나 API 설계를 어느 정도까지 할 수 있는가?
- 로그인, 회원가입, 권한 관리, 결제, 검색, 알림 같은 기능 중 직접 구현해본 것은 무엇인가?
- 배포까지 혼자 해본 경험이 있는가?
- 내가 만든 서비스 중 실제 사용자가 있거나 배포된 것은 무엇인가?
2. AI 개발자로서 할 수 있는 일
- 내가 직접 다뤄본 AI 모델이나 API는 무엇인가?
- OpenAI API, LangChain, Hugging Face, RAG, 벡터 DB 등을 사용해본 적이 있는가?
- AI 기능을 웹 서비스에 붙여본 경험이 있는가?
- 프롬프트 엔지니어링을 통해 성능을 개선해본 사례가 있는가?
- 이미지, 텍스트, 음성, 문서 처리 중 어떤 AI 기능을 구현해봤는가?
- AI 응답의 품질을 평가하거나 개선해본 경험이 있는가?
- AI 서비스에서 비용, 속도, 정확도 문제를 고려해본 적이 있는가?
3. 기술 스택 정리
- 내가 가장 자신 있는 언어는 무엇인가?
- JavaScript, TypeScript, Python 중 어느 정도까지 사용할 수 있는가?
- React, Next.js, Vue 같은 프론트엔드 프레임워크 중 익숙한 것은 무엇인가?
- Node.js, Express, NestJS, Django, FastAPI 중 사용해본 것은 무엇인가?
- MySQL, PostgreSQL, MongoDB, Redis 등 데이터베이스 경험은 어떤 것이 있는가?
- Docker, AWS, Vercel, Railway, Render 같은 배포 환경을 사용해본 적이 있는가?
- Git/GitHub을 협업 수준으로 사용할 수 있는가?
4. 프로젝트 경험 정리
- 가장 자신 있게 설명할 수 있는 프로젝트는 무엇인가?
- 그 프로젝트에서 내가 맡은 역할은 무엇이었는가?
- 어떤 문제를 해결하기 위해 만든 프로젝트인가?
- 사용한 기술 스택은 무엇이고, 왜 그것을 선택했는가?
- 개발 중 가장 어려웠던 문제는 무엇이었는가?
- 그 문제를 어떻게 해결했는가?
- 결과적으로 무엇이 개선되었는가?
- 프로젝트에서 아쉬웠던 점과 개선하고 싶은 점은 무엇인가?
- 이 프로젝트가 회사 업무와 연결된다면 어떤 가치를 줄 수 있는가?
5. 문제 해결 능력
- 최근에 해결한 가장 어려운 개발 문제는 무엇인가?
- 버그를 찾을 때 나는 어떤 방식으로 접근하는가?
- 모르는 기술을 배울 때 어떤 순서로 학습하는가?
- 에러 메시지를 읽고 원인을 추적한 경험이 있는가?
- 성능 개선을 해본 경험이 있는가?
- 코드 구조를 개선하거나 리팩토링한 경험이 있는가?
- 기술 선택을 할 때 어떤 기준으로 판단하는가?
6. 협업 능력
- 팀 프로젝트에서 맡았던 역할은 무엇인가?
- Git 브랜치 전략이나 PR 리뷰를 경험해본 적이 있는가?
- 기획자, 디자이너, 다른 개발자와 협업해본 경험이 있는가?
- 의견 충돌이 있었을 때 어떻게 해결했는가?
- 내가 작성한 코드를 다른 사람이 이해하기 쉽게 만들기 위해 무엇을 하는가?
- 문서화나 README 작성 경험이 있는가?
- 일정이 지연되었을 때 어떻게 대응했는가?
7. 취업 시장에서 어필할 강점
- 나는 AI 개발자와 웹 개발자 중 어느 쪽에 더 강점이 있는가?
- 두 분야를 함께 할 수 있다는 점을 어떻게 설명할 수 있는가?
- 내가 다른 지원자보다 차별화되는 점은 무엇인가?
- 회사가 나를 뽑으면 어떤 일을 맡길 수 있는가?
- 나는 빠르게 배워서 실무에 적용할 수 있는 사람인가? 그 근거는 무엇인가?
- 내가 가장 잘하는 개발 업무는 무엇인가?
- 내가 아직 부족하지만 성장 가능성을 보여줄 수 있는 부분은 무엇인가?
- 8. 이력서와 포트폴리오용 질문
- 내 프로젝트를 한 문장으로 설명하면 무엇인가?
- 각 프로젝트에서 내가 직접 구현한 기능은 무엇인가?
- 기술 스택을 단순 나열이 아니라 “왜 사용했는지” 설명할 수 있는가?
- GitHub에 코드가 정리되어 있는가?
- README에 설치 방법, 주요 기능, 트러블슈팅, 데모 링크가 있는가?
- 포트폴리오에서 가장 먼저 보여줄 프로젝트는 무엇인가?
- 면접관이 내 포트폴리오를 보고 궁금해할 만한 질문은 무엇인가?
9. 면접 대비 질문
- 자기소개에서 AI와 웹 개발 경험을 어떻게 연결해서 말할 것인가?
- 가장 자신 있는 프로젝트를 1분 안에 설명할 수 있는가?
- 사용한 기술의 장단점을 설명할 수 있는가?
- 내가 작성한 코드의 구조를 설명할 수 있는가?
- AI 기능을 붙일 때 발생할 수 있는 문제는 무엇인가?
- 웹 서비스에서 보안상 주의해야 할 점은 무엇인가?
- 입사 후 어떤 개발자로 성장하고 싶은가?
10. 최종 정리용 핵심 질문
- 나는 어떤 문제를 개발로 해결할 수 있는 사람인가?
- 나는 AI를 활용해 어떤 가치를 만들 수 있는가?
- 나는 웹 서비스를 어느 단계까지 책임질 수 있는가?
- 내 대표 프로젝트 3개는 무엇인가?
- 내가 바로 실무에서 기여할 수 있는 업무는 무엇인가?
- 내가 회사에 보여주고 싶은 가장 강한 증거는 무엇인가?
- “나를 한 문장으로 소개한다면” 어떻게 말할 수 있는가?-
