# 다항 분포
이항 분포가 2가지의 결과가 존재한다면, 다항분포는 결과가 3가지 이상인 사건의 발생 횟수를 말합니다.

다항분포는 다음과 같이 표현합니다.

`(X1, X2, X3) ~ Multinomial(n, p1, p2, p3)`

여기에서 
- `n`은 시행 횟수
- `Xk`은 각 카테고리가 나온 횟수
- `pk`은 카테고리가 나올 확률

을 말합니다.

![alt text](image-4.png)

> 해당 분포는 예시로 n번 실행하였을 때 클래스들이 얼마나 나타나는가에 대한 바이올린 분포입니다. 해석을 해보면 4~5가 가장 높은 빈도수로 등장하며 3이 미세하게 0, 1, 2클래스보다 많이 등장한다고 이해할 수 있습니다.

## 계산
다항 분포에서 `(X1, X2, X3, ..., xk) = (x1, x2, x3, ..., xk)`일 확률은 `P(X1=x1, ... Xk = xk) = n! * (1~k 곱)(pi^xi * (xi!)^-1)` 입니다.

- `n! / (x1! * x2! * ... * xk!)`: 해당 카테고리 형태의 순서가 나오는 경우의 수
- `p1^x1 * p2^x2 * ... * pk^xk`: 각 결과가 그 횟수만큼 나올 확률

평균은 카테고리별로 `E(Xi) = npi`이고 

분산은 `Var(Xi) = npi(1-pi)`입니다.

> 사실 이건 정확하게 검증까지는 하지 않았고, 앞으로 대략적인 의미만 파악한 뒤, 조심할 점 등만 알아가며 빠르게 훑어보려 합니다. (유명한 공식이니 문제 없어보입니다.)

### 중요한 조건
다항분포에서는 각 시행마다 결과가 하나만 나와야 하며, `(1~카테고리 개수의 시그마)pi = 1`이어야 하며, `(1~카테고리 개수의 시그마)Xi = n`을 만족해야 합니다.

### 중요
> 다항 문포의 각 카테고리는 서로 독립이 아니기 때문에 공분산이 성립하며 공분산의 비대각선 (좌상단~우하단 대각선 이외의 셀)은 모두 음수입니다.
