# 베르누이 분포
베르누이 분포는 결과가 딱 2개뿐인 사건을 한 번 실행했을 때의 분포입니다.

예를 들어 `학생이 내 수업을 들어 시험을 통과했다`를 `1`로 둘 시, `70%` 확률로 시험을 통과하게 된다면, `X ~ Bernoulli(0.7)`이 됩니다. 이는 `0.7의 확률로 X=1이 된다` 라는 의미와 같습니다.

![alt text](image-1.png)

베르누이 분포의 평균은 `p`이며 분산은 `p*(1-p)` 입니다.

예를 들어 시험 통과율이 `p = 0.7`이라면 평균은 `0.7`이며 분산은 `0.7 * 0.3 = 0.21`이 됩니다.

여기에서 평균은 한 학생의 결과는 무조건 `1` 또는 `0`이지만 많은 학생의 결과를 평균내면 `0.7`이 된다는 의미입니다.

## 베르누이 분포의 중요성
데이터 분석이나 머신러닝에서는 베르누이 분포가 **이진 분류의 기본**이 됩니다.

이는 다음 개념인 **이항 분포**를 이루게 하며 **베르누이 시행**을 여러 번 반복했을 때의 성공 횟수를 나타낼 수 있게 됩니다.
