# 경험적 분포
> 경험적 분포란 실제 데이터에서 관측된 값들이 어떻게 퍼져 있는지 나타낸 것

이는 이론적 분포가 아닌 실제 데이터를 통해 나타낸 분포를 말합니다.

예를 들어 점수가 `[1, 1, 5, 4, 7, 8, 98, 2]`가 나온다면 `{1: 2, 2: 1, 4: 1, 5: 1, 7: 1, 8: 1, 98: 1}` 형태로 나타낼 수 있습니다.

이를 점수의 경험적 분포라고 부릅니다.

경험적 분포에서는 실제 데이터에서 나온 비율을 확률처럼 보게 됩니다.

예를 들면 위 경험적 분포에서는 `1`의 비율이 `2/8 = 0.25 (25%)`가 됩니다.

## 분포
가장 간단한 예시가 파이썬의
```python
df["score"].value_counts()
```
입니다. (빈도분포)

또한 상대 빈도 분포는
```Python
df["score"].value_counts(normalize=True)
```
입니다. (각각 `[값: 0.xx]` 형태로 나옴)

### 누적 분포
어떤 값 이하가 전체의 몇 `%`인지 보는 것입니다.

예를 들면 위 데이터에서 `90`점 이하가 전체의 `(7/8 * 100)%` 형태가 됩니다.

이를 순서대로 50점 이하, 60점 이하, 70점 이하, ... 식으로 누적하며 확인이 가능합니다.

이는 pandas에서
```python
df["score"].value_counts(normalize=True).sort_index().cumsum()
```
를 통해 확인이 가능합니다.

### 수치형 데이터의 경험적 분포
수치형 데이터는 값이 너무 다양해서 `value_counts()`로만 보면 지저분해질 수 있습니다. (대부분의 값이 다르기 때문입니다.)

따라서 이런 수치형 데이터는 일반적으로 구간으로 나누어서 설정하게 됩니다.

예를 들어 사람의 키 같은 경우에는 `10cm` 단위로 나누어 셀 수 있습니다.

## 경험적 분포를 볼 때 확인할 것
위와 같은 데이터들을 히스토그램으로 나타낼 경우, 아래와 같은 특징들을 확인하며 데이터를 확인할 수 있습니다.
- 중심이 어느쪽으로 가있는지 (평균, 중앙값, 특정 값, 왼쪽/오른쪽)
- 얼마나 퍼져있는지 (IQR, 표준편차, 최소~최대)
- 어느쪽 꼬리가 긴지 (오른쪽 꼬리 = 대부분 작고 일부만 매우 큼 등과 같은 해석)
- 유난이 튀는 값이 나오는지
- 봉우리 개수가 많은지 (예를 들면 다른 IQ평균을 가진 집단끼리 합쳐지면 봉우리가 2개 나올 수 있습니다.)

## 경험적 분포를 확인한 후
경험적 분포를 확인한 다음, 해야할 일은 해당 분포를 어떤 이론의 분포와 닮았는지, 대조할 수 있으며 일반화 시킬 수 있는지를 판단하는 일입니다.

예를 들어 데이터가 위와 같이 점수에 대한 데이터라면 **비대칭 분포**, **쌍봉분포** 등과 같은 결과가 나올 수 있고, 성공/실패 비율에 따라 **베르누이 분포**의 이론분포를 생각해볼 수 있습니다.
