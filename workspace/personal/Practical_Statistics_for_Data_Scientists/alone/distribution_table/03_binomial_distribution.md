# 이항 분포
이항 분포는 **베르누이 시행**을 여러 번 반복했을 때 성공 횟수를 말합니다.

예를 들어 학생 `n`명 중 몇 명이 시험에 통과했는가? 라는 질문에는 시험의 **베르누이 분포**의 평균이 `0.7`인 경우, 아래와 같이 정리가 가능합니다.

`X ~ Binomial(n, 0.7)`

![alt text](image.png)

#### 베르누이 분포와의 관계
- 베르누이 분포: `한 명` | `한 번` | `0 or 1`
- 이항 분포: `여러 명` | `여러 번` | `성공 횟수`

베르누이 분포의 모습은 다음과 같이 하나하나로 생성됩니다. `[0] [1] [1] [1] [0] [1] [0] [1] [1]`

이때 이항 분포는 이 값들을 모두 더한, `[6]`이 됩니다.

## 수치를 계산하는 법
### 성공 확률
이항 분포는 정확히 `k`번 성공할 확률을 계산할 수 있습니다.
`P(X = k) = (n)C(k) * p^k * (1-p)^(n-k)` 입니다.

이는 `n중 k개가 나오는 경우의 수`, `성공한 k의 개수`, `성공하지 않은 (n-k)의 개수`를 뜻합니다.

### 평균과 분산
이항 분포의 평균은 `n*p`입니다. 

분산은 `n*p*(1-p)`이며 표준편차는 분산에 루트를 씌운 값입니다.


## 이항분포의 성립 조건
1. 시행 횟수 `n`이 정해져 있어야함
2. 각 시행 결과가 2가지로 나뉠 수 있어야함
3. 각 시행의 성공 확률 `p`가 같아야함
4. 각 시행이 서로 독립적이어야 함

이라는 조건이 필요합니다. 예를 들어 동전던지기는 위 조건을 모두 만족합니다.

하지만 카드뽑기와 같은 뽑고, 다시 넣지 않는 경우에는 앞의 결과가 뒤에 영향을 줍니다. 이는 **초기하분포**에 더 가까운 모습이 됩니다.
