# 웹캠 프로젝트
이번에 과제로 웹캠으로 저희 얼굴에 대한 내용을 `cv2`를 이용하여 저장한 후 모델을 학습, 학습된 모델과 함께 영상을 녹화하는 시점에 그 얼굴을 인식하며 cv2의 기능을 이용하여 출력되는 디스플레이에 AR기능, 기타 효과 기능 등을 보여주면 되겠다고 이해하였습니다.

흐름을 조금 더 정돈된 형태로 작성해본다면
### 1. 데이터 만들기
1. 웹캠 frame
2. 얼굴 검출
3. 얼굴 영역 crop
4. 이미지 encoding / 저장
5. 사람별 폴더

아래와 같이 저장
```aiignore
dataset/
- 사용자_1/
- 사용자_2/
```

### 2. 모델 학습하기
1. 저장된 얼굴 이미지
2. Dataset / Transform (ImageFolder)
3. DataLoader
4. 전이학습
5. 사람별 분류 학습
6. `model.pth` + `class` 정보 저장

### 3. 실제 프로그램
1. 웹캠 frame
2. 얼굴 검출 (모델에 실시간으로 넣어서 누구인지 뽑기)
3. pytorch용 resize / normalize
4. cnn 추론
5. 누구인지 식별
6. opencv 화면에 출력

이를 위해 폴더를 다음과 같이 나누려 합니다.
- `app/`: 실제 어플
- `training/`: 얼굴 인식 어플
- `data/`: 저장한 얼굴 데이터들과 이를 `hurwan_train.py`/`validation`으로 나눈 폴더
- `models/`: `.pth` 저장 폴더
