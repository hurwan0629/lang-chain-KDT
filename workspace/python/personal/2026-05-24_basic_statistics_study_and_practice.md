# 그냥 행렬, 벡터, 등에 대한 연습 공간

일단 행렬 곱 (X, @, w, Y 등에 대한것들) 한 상태.

벡터 내적, 거리등은 알고 코사인 유사도 하는중.

# 코사인 유사도
코사인 유사도는 두 벡터의 방향이 얼마나 비슷한지.

`[코사인 유사도] = [A]·[B] / ([|A|] x [|B|])` 

> [두 벡터의 내적] / [두 벡터 크기의 곱]

- `-1`일 수록 방향이 완전히 다른것이고
- `1`일수록 완전히 같은 방향이다.

## 문제1. 
A = [1, 0]
B = [0, 1]

코사인 유사도는?

```
벡터 내적 = 0
분모 구할필요 없음.

> 0
```

## 문제 2.
A = [1, 2]
B = [2, 4]

코사인 유사도는?

```
벡터 내적 = 10
분모: 루트 5 곱하기 루트 20 = 2루트5 -> 10

따라서 1
```

# 행렬곱
A @ B = (m, n) @ (n, k) = (m, k)로 나온다. 두 행렬의 앞부분의 속성 개수가 뒷부분 가중치의 행(속성) 개수와 같아야한다.

## 문제 1
A = [
  [1, 2],
  [3, 4]
]

B = [
  [5],
  [6]
]
A @ B = ?

```
[
    [(5 + 12), (15 + 24)] = [17, 39] 
]

--- 틀림. 모양이 잘못됨.

[
    [17],
    [39]
]
```

  [4, 5, 6]
]

B = [
  [1, 2],
  [3, 4],
  [5, 6]
]
A @ B = ?

```

    [(2 + 8 + 18) = 28, (8 + 20 + 36) = 64],

[
    [(1 + 6 + 15) = 22, (2 + 8 + 18) = 28],
    [(5 + 15 + 30) = 50, (8 + 20 + 36) = 64],
]
```

# bias
`b`는 **bias**로 편향이라고 한다.

가중치는 각 속성이 결과에 얼마나 영향을 주는지 이다.

하지만 속성값이 전부 0이어도 기본적으로 깔리는 값이 있을 수 있기 때문에 기본값을 주는 경우가 있다.

`b`는 스칼라가 아닌 벡터의 형태일 수도 있다.

# 회귀와 분류
머신러닝에서 `X @ w + b`의 결과를 해석하는냐에 따라 크게 나뉠 수 있습니다.
### 회귀
숫자 하나를 예측하는 문제. 내일 주가, 집값, 내일 기온 등

- X: (데이터 개수, 속성 개수)
- W: (속성 개수, 1)

이를 통해 결과가
```
[
    [a],
    [b],
    [c],
    ...
]
```
형태로 나와 데이터에 따른 예측 결과들이 몇개 나오는 방식입니다.

기온으로 따지면 날짜별 예측과 결과에 대조하여 차이가 가장 적은쪽으로 수렴하는 방식으로 `w`가 조절될 것 입니다.

### 분류
여러 후보 중 하나를 고르는 문제입니다.

> 예시로 동물의 종류중 [개, 고양이, 말, 기린, 기타] 중에 하나 고르는 느낌이 있습니다.

형태는 
- W: (속성 개수, 클래스 개수) 

형태로 위의 예시로 들면 (속성 개수, 5) 형태가 되며, 위 5종류중 하나의 값이 가장 클 때 그 값으로 분류하는 방식입니다.

처음 `W`를 랜덤한 숫자로 둔 뒤 점점 정답 `y`와 비교하며 `loss`가 적게 조금씩 수정해 나가는 쪽입니다.

## 분류 모델
분류 모델은 보통 마지막에 `[a, b, c ... ]` 등과 같은 점수를 내게 됩니다.
### softmax
`softmax`는 나온 점수들을 확률처럼 해석 가능한 값으로 바꿔주게 됩니다.

이를 통해 점수들을 차이에 따라 가장 큰 점수가 높은 확률, 낮은 점수가 낮은 확률로 `0`~`1`의 형태로 강조되게 됩니다.

자연상수(e)와 전체 데이터 `data`일 때, 데이터 `n`의 확률 공식은
`softmax(n) = e^n / sum(data^e)` 형태 입니다.
### loss
이렇게 구한 데이터들의 확률을 통해 모델이 얼마나 틀렸는지 나타내는 값인 `loss`에 대해서 알아보겠습니다.

`loss`란? 모델이 얼마나 틀렸는지 나타내는 값 입니다.

예를 들어서 `[개, 고양이, 사람]` 클래스에서 한 프레임의 결과로 `[0.7, 0.2, 0.1]`을 낸다면 모델은 많이 틀렸다고 볼 수 있습니다. 이때, `loss`가 크게 만들어집니다.

보통 위에서 고양이가 정답인 경우에는 값을 `[0, 1, 0]` 형태로 만들게 됩ㄴ디ㅏ.

**회귀**에서는 정답 `y`(스칼라)와 예측 값을 비교하여 `loss`를 만듭니다.

**대표적인 방법으로는**
- 회귀의 `MSE`: 오차 제곱 평균 
- 분류의 `Cross Entropy`: 정답 클래스에 확률을 얼마나 줬는지

이 있습니다.
