# 시작
## 탐색적 데이터 분석 (EDA)
*탐색적 데이터 분석 (p.19) 부터 시작하겠습니다.

고전적인 통계학에서는 거의 대부분 **추론**, 즉 적은 표본을 통해 더 큰 모집단에 대한 결론을 도출하기 위한 복잡한 과정에 대해 다루었습니다. (데이터를 많이 모으지 못해서.)

1962년 즘부터 존 투키가 데이터 분석에 대한 컴퓨터 과학 분야에 대해서 이어서 설명을 하기 시작햇다고 한다.

1977년 `탐색적 데이터 분석` 이라는 책을 통해 정립되었다고 한다. 요약통계, 도표 등이 제시되었다.

요즘에는 센서측정, 이벤트, 텍스트, 이미지, 비디오 등 많은 소스로 부터 데이터를 얻을 수 있다.

위의 정보들은 정형화 되지 않은 상태라고 알 수 있다.

이러한 원시 데이터를 활용 가능한 형태의 정보로 변환하는 것은 중요하다.

수치 데이터의 종류는
- 수치형 데이터
  - 연속형 데이터: 시간, 온도, 소득 등
  - 이산 데이터: 발생 빈도
- 범주형 데이터
  - 이진 데이터: 2개 유형으로 나뉘는 데이터
  - 순서형 데이터 (순위): 크고 작음이 있는 연속적이지 않은 데이터 (기분지수, 평점)

등이 존재한다.

일반적인 프로그래밍의 DB에서는 이미 문자나 숫자의 집합에서 데이터베이스 내부에서도 처리가 가능한데 이것을 범주형인지, 그냥 수치인 것인지를 나누면 이점이 3가지가 나온다.
- 모델 피팅, 차트생성 등에 어떤 것을 쓸 지 판단할 수 있다.
- 인덱싱, 저장소를 최적화 할 수 있다.
- 범주형 변수가 취할 수 있는 값들을 소프트웨어적으로 처리가 가능하다. (like enum) (하지만 새로운 값이 들어오면 NA가 나올 수 있다.)


## 1.2 테이블 데이터
데이터분석에서 가장 대표적으로 사용되는 객체의 형태는 `엑셀` 또는 `데이터베이스(테이블)` 이다.

이러한 `레코드`x`속성 열` 형 데이터가 데이터 학습에 적합한 형태의 데이터이다.

이떄 변수는 2가지로 나뉘게 되는데
- 지표변수: 결과에 영향을 주는 변수. 학습에서 인자값에 해당한다 할 수 있다. 
- 결과변수: 지표 변수를 통한 맞음/틀림을 결정할 수 있는 변수. 이 것을 맞추기 위해 학습이 진행된다.

### 1.2.1 데이터 프레임과 인덱스
보통 테이블 데이터에서는 1개 이상의 열에 인덱스를 설정하게 된다. 이를 통해서 데이터에 인덱스를 통해 빠르게 접근이 가능하다.

### 1.2.2 테이블 형식이 아닌 데이터 구조
시계열 데이터는 동일한 변수 안에 연속적인 측정값을 갖는다. 이를 통해 나온 예측된 데이터는 다양한 디바이스에서 중요한 요소가 된다.

위치 정보 분석에 사용되는 공간 데이터의 경우에도 공간좌표가 데이터의 중심이 되며, 필드 정보의 경우에는 픽셀의 밝기 등이 데이터의 중점이 된다. 네트워크 관계에서는 그래프가 좋은 사용 데이터가 된다. (이때 통계학에서의 그래프는 연결 관계라기 보다는 다양한 도표와 시각화 방법을 의미한다.)

### 1.3 위치 추정
데이터를 표현하는 변수들은 보통 수천가지 다른 값을 갖는다.

데이터를 분석하는 가장 기초적인 단계는 **대푯값**을 구하는 것이다.

> 대푯값의 종류
- 평균
- 가중평균: 가중치를 곱한 값의 총합을 가중치의 총합으로 나눈 값

![가중평균 수식](https://mblogthumb-phinf.pstatic.net/MjAyMzAzMzBfNDQg/MDAxNjgwMTc2NjU1NDMz.268RTW3sJdwMN5olqP3nE5JQ6THPJWaoCjUq4KZm2Ccg.Hz_Yr5QNMxsnEZ5baKICo022DatQEAyBlgz_k6kXr_gg.PNG.ycpiglet/1f0f402e031e996001f9126659b9e472dc46da7e.png?type=w800)
- 중간값
- 백분위수: 전체 데이터의 P%를 아래에 두는 값
- 가중 중간 값: 데이터를 정렬한 후 각 가중치 값을 위에서부터 더할 때, 총합의 중간이 위치하는 데이터 값 (가중치들의 합에서 2로 나눈 후 누적 가중치가 넘어가는 첫번 째 값.) (데이터의 중요도가 제각각이기 때문에 가중치를 다르게 주는데 이걸 그냥 평균을 구하면 실제 중요도는 적용이 안될 수 있기 때문에 가중치가 중간쯤 될 때가 중심이라 판단하는 방식)

```

| 점수 | 가중치 | 누적 가중치 |
|---:|---:| ---:|
| 10 | 1 | 1 |
| 20 | 2 | 3 |
| 30 | 7 | 10 | 

와 같은경우에서 처음으로 누적 가중치가 5를 넘는 점수는 30 -> 가중 중간값은 30이다.

```

- 절사평균: 정해진 개수의 극단값을 제외한 나머지 값들의 평균 (이상치 뺀 평균정도)
- 로버스트: 극단값들에 민감하지 않음을 의미
- 특잇값: 대부분의 값과 매우 다른 데이터 (이상치)

평균은 구하기도 쉽고 사용하기도 편하지만 데이터의 중간을 표현하지 못하는 경우가 많다. (극단값과 중요도가 다르기 때문이다.)

중간값과 가중 중간은 로버스틱 하다 할 수 있다.

( ~ p.30)
