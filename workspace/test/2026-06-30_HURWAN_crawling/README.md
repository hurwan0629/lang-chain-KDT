### 탐색 url
- 예스 24: `http://www.yes24.com/Main/default.aspx`
- 교보문고: `http://www.kyobobook.co.kr/`
- 알라딘: `https://www.aladin.co.kr/home/welcome.aspx`

함수: `crawl_start("검색할 키워드", 알라딘 페이지 수[int], 알라딘 페이지 수[int], 알라딘 페이지 수[int])` [ex: `crawl_start("keywords", 1, 2, 3)`]


### 탐색 및 저장 형태
요구사항: `| 검색어 | 책제목 | 저자 | 가격 | 출판사 | 출판일 | 이미지 |`
실제 저장 column: `| title | author | price | publisher | pub_date | image_link |`

> `image_link`는 파일 경로입니다.

### 예외 처리
1. 검색 결과가 없는 경우: 결과가 없음에 따라 시트 저장 작업 자체를 진행하지 않습니다.
2. 페이지가 존재하지 않는 경우: 그럴 경우가 매우 낮지만 해당 사건 발생 시 404가 발생한 사이트만의 크롤링이 중단됩니다. 다른 페이지가 존재하는 사이트는 정상 동작 합니다.
3. 이미지 다운로드 실패: 이미지 다운 실패 시 19세 이미지 또는 보안이 적용됨으로 판단하여 `"이미지 없음"`로그가 발생하며, 엑셀에는 `None`으로 저장합니다.
4. 요소 탐색 실패: 제목 탐색 실패, 특정 정보 수집에 실패할 경우에는 진행됩니다. 반대로 다음 페이지 링크 탐색 실패 등과 같은 치명적인 오류시 해당 사이트의 크롤링을 중단합니다.
5. 사이트 로딩 지연: 최소 3초, 최대 10초까지 기다릴 수 있습니다. 초기 로딩시에는 여러 대기 작업들이 존재하여 약 20초 이하의 준비시간이 걸릴 수 있습니다.
6. 검색 결과 부족 시 자동 종료: 검색 결과 부족이 검색 결과가 없는 경우`(1)`과 유사하여 동일하게 취급하였습니다.
7. 이미지 확장자 자동 처리: `Content-Type`를 기반으로 [설정 파일](./my_lib/config.py)의 `EXT_MAP`을 통해 처리하였으며 해당 딕셔너리에 존재하지 않는 타입의 경우에는 `.jpg` 파싱을 시도합니다.

### 조건
* 소스코드는 .py 파일로 저장
* 이미지 경로는 images 폴더 생성 후 각 도서판매 사이트 별도로 폴더 생성 후 저장(yes24, kyobo, aladin)
* 크롤링 프로그램은 함수형으로 작성하되 각 사이트의 크롤링할 페이지 번호를 입력하도록 작성 
예) crawl_start('검색어', 3, 5, 4) # 예스24는 3페이지, 교보문고는 5페이지, 알라딘은 4페이지까지 크롤링
* 제출시 소스코드와 엑셀파일을 압축하여 업로드
* 저장 구조는 아래와 같이

```md
`datas/`
  └── `search_[%Y]-[%m]-[%d]_[keywords]_[yes24_num]_[kyobo_num]_[aladin_num]/`
        ├── `images/`
        |     ├── `yes24/`
        |     ├── `kyobo/`
        |     └── `aladin/`
        └── `datas.xlsx`
```

### 특이사항
- 이미지가 19금 또는 보안에 의해 종종 다운되지 않는 경우가 있습니다. 해당 경우에는 `None`로 저장됩니다.
- 예스24와 알라딘의 경우 출판일의 일(day)을 상세 페이지에서만 제공합니다. 이때 하나하나 모두 들어가는데 걸리는 시간에 비해 데이터의 가치가 높지 않다고 판단해 순회하지 않았습니다.
