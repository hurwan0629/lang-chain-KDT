# MongoDB
- NoSQL 데이터베이스 시스템 중 하나로, 문서 지향 데이터베이스
- 관계형 데이터베이스와는 다르게 데이터를 테이블이 아니라 JSON 스타일의 BSON(Binary JSON) 형식의 문서로 저장
- 개발자가 유연하게 데이터를 저장하고 쿼리할 수 잇도록 목적으로 만들어짐

문서 지향 데이터베이스
데이터를 BSON 형식의 문서로 저장. 이 문서는 키-값 쌍으로 이루어져 있으며, 여러 종류의 데이터 유형을 포함할 수 있음

스키마가 없음.
- 관계형 데이터베이스와 달리 MongoDB는 데이터베이스의 스키마를 명시적으로 정의하지 않음
- 동적인 스키마를 사용하여 데이터 모델을 유연하게 변경할 수 있도록 함

 {"no": 1, "userid": "apple", "userpw": "1111" }
 {"no": 2, "userid": "banana", "userpw": "2222", "email": "banana@banana.com"}
 {"name":"오렌지", "hp":"010-1111-1111"}
