노드 JS란?
- 브라우저 밖에서도 자바 스크립트를 실행할 수 있도록 만든 서버 측 자바 스크립트 실행 환경입니다.
- 구글의 V8 엔진을 기반으로 동작
- 웹 서버, API 서버, 실시간 채팅, 스트리밍 서비스 등 활용
- npm(Node Package Manager)을 통해 수많은 오픈소스 패키지를 쉽게 사용할 수 있어 빠른 개발이 가능
- 프론트엔드와 동일한 언어(JavaScript)를 사용한다는 점에서 풀스택 개발에 매우 유리한 환경이다.

사람들이 글을 많이 쓰고, 입력 받을 때 노드Js 환경을 많이 이용한다. (빠른 반응 간으)

프론트엔드, 백엔드 역할 차이

- 프론트엔드는 사용자가 직접 보고, 상호작용하는 화면(UI)을 구현하는 영역. HTML/CSS/JavaScript를 사용해 버튼, 입력창, 화면 레이아웃, 애니메이션 등 사용자 경험을 담당
- 백엔드는 사용자의 요청을 받아 데이터를 처리하고, 데이터베이스와 연결하여 지정/조회/수정/삭제 등의 로직을 수행하는 서버측 영역

패키지 매니저
- Node.js 환경에서 필요한 라이브러리(패키지)를 설치, 관리, 업데이트할 수 있게 도와주는 도구

package.json
- Node.js 프로젝트의 정보를 담고있는 핵심 파일
- 패키지에 대한 설명서(프로젝트 이름, 버전, 필요한 패키지 목록, 실행 스크립트 등 다양한 정보를 담고 있음)

```json
{
  "name": "17_nodejs", // 프로젝트 이름(소문자로 작성/공백X)
  "version": "1.0.0", // 프로젝트 버전
  "main": "index.js", // 진입점 파일
  "scripts": { // 터미널에서 실행 명령어
    "test": "echo \"Error: no test specified\" && exit 1"
  },
  "author": "", // 제작자 이름
  "license": "ISC", // 사용한 라이선스
  "description": "", // 설명
  "type": "commonjs" // 프로젝트 방식
}
```

웹 서버
- 사용자의 브라우저 요청을 받아 웹 페이지, 이미지, CSS, JavaScript 같은 파일을 전달해주는 서버 프로그램 또는 시스템
- 사용자가 주소(URL)을 입력하면 웹 서버는 해당 요청을 처리하고 필요한 파일이나 데이터를 응답으로 보내며, 이 과정을 통해 브라우저에 웹 사이트 화면이 표시됨

모듈
- 모듈은 프로그램을 기능별로 나누어 독립적인 파일이나 단위로 구성한 것으로, 코드의 재사용성과 유지보수를 쉽게 해주는 구조
- 특정 기능(계산, 인증, 데이터 처리 등)을 하나의 파일로 분리해두면, 다른 파일에서 필요할 대 불러와 사용할 수 있음
- `require()` 또는 `import`를 통해 모듈을 가져올 수 있음


CommonJS vs ES6 모듈 차이

- CommonJS
  - node.js 기본 방식
  - 모듈 가져오기 require('파일')
  - 모듈 내보내기: module.exports 또는 exports.이름
  - 확장자: .js
- ES6
  - ES6 지원하는 브라우저 또는 node.js 환경
  - 모듈 가져오기: `import { 이름 } from '파일'`
  - 모듈 내보내기: `export`, `export default`
  - 환장자: .mjs
