`$regex`
- MongoDB의 문자열 패턴 검색
- `text: {{ $regex: "공부" }}`
  text안에 "공부"라는 문자열이 포함된 문서를 찾겠다는 뜻

`$option`: "1"
- 대소문자 구분 없이 검색하겠다는 뜻

put
- 서버에 이미 존재하는 자원을 전체적으로 수정하거나 특정 자원을 새로 생성할 때 사용하는 방식
- 클라이언트는 수정할 데이터 전체를 요청 본문에 담아 서버로 전달하며, 서버는 해당 자원을 전달받은
데이터로 완전히 교체하는 방식으로 업데이트

patch
- 서버에 존재하는 자원의 일부 데이터만 부분적으로 수정할 때 사용하는 방식
- 클라이언트는 수정이 필요한 필드만 요청 본문에 담아 서버로 전달하며, 서버는 해당 자원의 특정
부분만 업데이트
