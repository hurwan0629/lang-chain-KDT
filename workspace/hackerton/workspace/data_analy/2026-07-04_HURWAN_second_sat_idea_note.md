# 사용 흐름 예상도
공공 기관에서 안전 대비 및 인프라 구축 등을 위해 사용하는 어플리케이션 및 API 를 제공하는 방식의 서비스입니다.

1. 지자체 등 공무원들이 해당 서비스에 접속
2. 서비스가 기온, 시민 분포, 지도, 시간대, 위치 별 위험도 수집
3. 서비스가 주변에 이미 인프라가 있는지 확인
4. 화면에 해당 지역 및 정보들을 지도 등과 같은 형태로 시각화 (기상청 격자와 비슷하게)
5. 서비스가 각 지역의 폭염 또는 기타 노출 위험도를 계산
6. 각 지역의 취약계층 밀도에 따라 위험 점수를 높인다.
7. 각 지역의 도움 접근성을 계산한다.
8. 위험지역 TOP 목록을 확인
9. 특정 지역을 클릭하면 위험 원인을 보여주기 (취약계층 목록 또는 인프라 부족, 체감온도, 응급의료기관 부족 등)
10. 서비스가 대응 방안을 추천한다. (독거노인 안부전화, 냉방용품 지원, 무더위 심터 추가 지정 후보 검토 등)
11. 담당자가 대응 계획을 확정
12. CSV, 엑셀, PDF 보고서, 지도 이미지 등으로 저장
> 대응 이후
13. 대응 결과를 기록
14. 예측한 위험지역에서 실제 환자가 발생했는지 확인
15. 실제 발생 결과를 반영해서 위험 점수 계산 방식을 보정

> **지도 + 위험지역 순위 + 위험 원인 + 대응 추천** 서비스
> API의 경우에는 공개 API와 함께 API KEY를 특정 인증된 사용자에게 제공 (이를 통해 추가 이용 기업들에게 공익적 데이터를 제공할 수 있음)
