# 머신러닝과 데이터 과학
이번에는 `pandas`, `matplotlib`, `scikit-learn` 등의 라이브러리를 이용해서 데이터 분석의 큰 흐름을 알아보려 합니다.

일반적으로 데이터를 이용해서 ai를 만든다는 것은 지도/비지도 방식으로 정답이 있거나 없는 방식으로 구분을 하며 다른 구분 방식으로는 분류/회귀 방식으로 집단을 나눌 것인가 또는 숫자를 예측할 것인가 등으로 구성이 나뉠 수 있습니다.

인공지능을 만든다는 것은 큰 흐름에서 다음과 같습니다.
1. 데이터를 가져와 분석합니다. 이 과정에서 데이터를 재가공하거나 데이터를 기계가 학습하기 좋은 숫자형 데이터 또는 불린 과같은 데이터같이 가중치를 적절히 줄 수 있는 형태로 구성하게 됩니다. 예를 들면 데이터 타입을 바꾸고, 이상치를 제거하며 결측치를 적절히 채우기도 하고, 중복값을 확인하거나 정규화/표준화를 시키기도 합니다.
2. 데이터의 통계와 시각화를 직접 학인합니다. 앞에서 설명한 전처리를 하기 위한 사전 작업으로 데이터가 어떤 형태를 가졌는지 평균, 중앙값, 최빈값, 분산, 표준편차, 범주별 개수, 히스토그램, IQR 등과 같은 이상치를 확인하고 이것이 적절한 형태의 데이터인지, 사용해도 되는 데이터인지 확인하는 절차를 가지게 됩니다.
3. 학습/검증/테스트 하며 인공지능을 학습하게 됩니다. 여기에서 중요한 개념으로는 학습용 데이터, 검증용 데이터, 테스트용 데이터의 비율과 그를 나누는 방식, 이것을 학습시킬 때 사용하는 모델 또는 파라미터, 파라미터를 어떻게 사용할것인지를 나타내는 하이퍼 파라미터, 예측하는 방식 등을 결정하게 되는데 여기에서 선택하는 전략이 데이터 전처리만큼이나 만들 모델 성능에 직접적인 영향을 주는 요소가 됩니다.
4. 결과평가 단계에서는 학습 및 검증 데이터를 사용하여 결과를 예측해내는 ai 모델을 이용하여 테스트 데이터를 예측해본 뒤 그 예측 결과에 따라 얼마나 모델이 잘 만들어졌는지를 판단하게 됩니다. 여기에서 분류의 경우에는 정확도, 혼동행렬, 정밀도, 재현율, f1 점수를 사용하며 회귀에서는 주로 mae, mse, rmse, r^2를 사용하게 됩니다.
5. 위에서 작업한 점수들을 바탕으로 그 결과를 해석하는 과정을 가지게 됩니다. 결과 정확도가 높더라도 어떤 것은 진짜로 모델이 잘 나온 것일 수 있으며 어떤 경우에는 모델이 데이터를 그대로 학습한 형태에 가깝거나 그 데이터를 간접적으로 알게되어 모델이 과적합 된 상태일 수 있습니다.

> 파라미터의 경우에는 모델이 학습을 통해 찾아가는 값을 말하며 하이퍼 파라미터는 학습하기 전에 모델의 학습 방향을 결정하는 사람이 결정하는 값입니다.
