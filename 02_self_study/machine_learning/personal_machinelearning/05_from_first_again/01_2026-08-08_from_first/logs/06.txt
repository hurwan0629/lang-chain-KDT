기존에 WTX + b = 0 이라는 공식이 있고 WT는 행벡터인거고 X는 그냥 열벡터(일반 벡터) 인 것이여서 
w1Tx1 + w2Tx2 + ... + b 형태가 되는건데 여기에서 W는 정확히는 모르지만 일단 수직이기 때문에 어떤 점이든 기존 함수와의 거리를 재고싶으면 W에 투영하면 거리가 나온다는거잖아?

꼭 이었을때 수직이 되는 직선이 아니여도 그냥 선분만 나오면 w에 투영해버려서 길이를 찾아버리는거고.

여기에서 기존 직선 또는 함수를 경계 라고 부르고 그 위의 점을 x0 이라고 할 때 x0 - x 는 두 점 사이의 벡터이니까 이걸 w에 투영을 하는거고


(x0-x)TW = ||x0-x|| ||W||cosC 가 되는건데 우리가 구하려는건 ||x0-x|| 의 cosC를 가한 값이기 때문에 ||W||를 이항해주면 원하던 식이 나오는거고.

여기에서 분자를 풀면WTx - WTx0 가 되는건데 (여기에서 내적 푸는것도 잘 모르는데 일단 썼어) 그러면 WTX0 + b = 0 이라는 사실을 통해 
WTx + b 가 나오게 되고, 그거를 이용해서 결국 거리 공식이 나오는거네. 부호는 아마 cos 각도에 의해서 생기는거같고.

그러고 아까 말했던 wTx + b 자체는 그냥 경계일 분 아니야? 이거 굳이 설명했던 이유가 뭐야? 애초에 푼다고 하나? 아무튼 공식을 이용해서 절대적인 거리 공식을 얻었는데 ||w|| 가 있으니까 그냥 있다고 하는거지 왜 굳이 2배 이야기를 했던거야?
