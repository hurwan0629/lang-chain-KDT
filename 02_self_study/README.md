# 02 Self Study

개인 복습, 책 정리, 개념 노트, 수업 외 추가 실습을 모아둔 영역입니다.

## Folders

- `python/`: Python 언어 복습, 데코레이터, 모듈, 제너레이터, Selenium/pandas 일부 실습
- `data_analysis/`: pandas, numpy, 주식 데이터, 데이터 분석 복습
- `statistics/`: 통계 책 정리와 분포 노트
- `math/`: 선형대수, 확률/통계, ML 수학
- `algorithms/`: 정렬, heap, graph, Dijkstra, greedy/DP
- `c_language/`: C 언어, 배열, 연결 리스트, 트리, 그래프, 해시맵
- `cs/`: 운영체제, 프로세스, 메모리, 파일 시스템, 네트워크, 스케줄링
- `software_engineering/`: 소프트웨어공학, 요구사항, 프로세스 모델
- `devops/`: Linux, Docker, WSL, 서버 환경 메모
- `ai_llm/`: GPT API, LLM, AI 관련 노트
- `authentication/`: 인증/인가 실습
- `database/`: DB 관련 개인 노트
- `javascript_node/`: Node 관련 개인 실습
- `react/`: React 개인 실습
- `typescript/`: TypeScript/Zod 실습
