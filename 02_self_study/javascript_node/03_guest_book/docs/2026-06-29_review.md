# 프로젝트 모듈화 해보기
현재 프로젝트는 로직이 오직 server.js에서 돌아가고 있습니다.

해석을 못할 수준은 당연히 아니지만 확장하기 불편한 요소임은 확실하게 알 수 있습니다.

이에 따라 다른 역할이거나 반복되어 사용되는 코드들을 한번 확인해보려 합니다.

- `app.use`: 미들웨어는 따로 관리해도 될 것 같습니다.
- `파일 시스템`: 파일 시스템을 쓸 때마다 `registLog.csv`, `user.json`을 확인 -> 생성 -> 읽어오기 -> 수정하기 기능이 반복되고 있습니다.
- 쿠키에 있는 `userCode`를 확인하는 작업이 매번 반복 되어야할 것으로 확인됩니다.
- `응답 및 요청 데이터`: 급한 요소는 아닙니다. `express.json()`, `express.urlencoded()` 등을 통해 요청 파싱은 자동으로 해주지만 요청/응답 형태가 고정되지 않아서 유지보수와 일관성에 지장이 있을 수 있습니다.
