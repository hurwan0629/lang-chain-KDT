1. 경험적 분포
경험적 분포: 실제 데이터에서 관측된 값들의 분포
2. 이산형 기본 분포
베르누이분포: 성공/실패처럼 결과가 0 또는 1일 때 쓰는 분포
이항분포: 성공/실패를 여러 번 반복했을 때 성공 횟수를 다루는 분포
기하분포: 첫 성공이 나올 때까지 몇 번 시도하는지 다루는 분포
음이항분포: r번째 성공이 나올 때까지의 실패/시도 횟수를 다루는 분포
다항분포: 결과가 여러 범주일 때 각 범주가 몇 번 나오는지 다루는 분포
3. 사건 발생 횟수 계열
포아송분포: 일정 시간·공간·범위 안에서 사건이 몇 번 발생하는지 다루는 분포
지수분포: 다음 사건이 발생할 때까지의 대기시간을 다루는 분포
감마분포: 여러 사건이 발생할 때까지의 대기시간이나 양수형 데이터를 다루는 분포
4. 연속형 기본 분포
균등분포: 일정 구간 안의 모든 값이 같은 가능성을 가질 때 쓰는 분포
정규분포: 평균 주변에 값이 몰리고 양쪽으로 퍼지는 종 모양 분포
표준정규분포: 평균 0, 표준편차 1로 표준화한 정규분포
5. 표본분포 계열
표본평균의 분포: 여러 표본에서 계산한 평균들이 어떻게 흔들리는지 나타내는 분포
표본비율의 분포: 여러 표본에서 계산한 비율들이 어떻게 흔들리는지 나타내는 분포
평균 차이의 분포: 두 집단 평균 차이가 표본마다 어떻게 달라지는지 나타내는 분포
검정통계량의 분포: t값, 카이제곱값, F값 같은 통계량들이 따르는 기준 분포
6. 통계적 추론 / 검정용 분포
t분포: 표본이 작거나 모표준편차를 모를 때 평균 추정·평균 비교에 쓰는 분포
카이제곱분포: 범주형 빈도 차이, 독립성 검정, 분산 검정에 쓰는 분포
F분포: 여러 집단 평균 비교, 분산 비교, 회귀모형 비교에 쓰는 분포
7. 데이터 과학에서 자주 만나는 응용 분포
로그정규분포: 값이 0보다 크고 오른쪽 꼬리가 긴 데이터에 자주 쓰는 분포
긴 꼬리 분포: 소수의 큰 값이 전체에 큰 영향을 주는 데이터에서 보이는 분포
멱법칙 분포: 순위가 높을수록 극단적으로 큰 값을 가지는 현상을 설명하는 분포
혼합분포: 여러 집단의 분포가 섞여 하나처럼 보이는 분포
8. 베이지안/확률 모델 확장
베타분포: 0~1 사이의 확률값 자체를 다룰 때 쓰는 분포
이론적 분포: 수학적으로 정의된 기준 분포
