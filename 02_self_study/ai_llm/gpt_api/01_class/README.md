# 프롬프트 엔지니어링

- 인공지능 모델 특히 자연어 처리 모델과의 사호작용을 최적화하는 기술
- 모델이 의도한 답변을 도출하도록 텍스트를 구성하는 방식으로 적절한 지문 형식이나 설명을 제공하여 더 나은 성과를 얻는것을 목표로 함

## 1. Role

AI모델과의 대화에서 특정 문맥을 설정하거나, 모델의 응답 스타일과 관점을 조정하기 위해 사용하는 개념

- User: Ai와 상호작용하는 주체로, 일반적인 질문이나 요청을 전담
- Assistant: AI 모델이 자체적으로 응답할 때의 역할로, 사용자의 질문이나 명령에 따라 답변을 제공
- System: AI모델의 행동과 스타일을 지시하는 역할로, AI가 어떻게 응답해야 할지 지침을 설정

## 가격
1. GPT x.x.SOL
- 가장 성능이 좋은 모델
- 긴 코드 이해 및 생성
- 복잡한 버그 수정
- 가장 비쌈 (Terra/Luna 보다 느림)
- RAG, LangGraph, 복잡한 FastAPI 프로젝트, 논문 분석, 의료 AI 등

2. GPT x.x Terra
- Sol에 가까운 성능(비용은 절반수준)
- 성능과 비용의 균형 모델

4. Input

- GPT에게 보내는 토큰
- 매 요청시

5. Cached input

- 이전에 보낸 입력을 재사용
- 캐시가 존재할 때

6. Cache writes

- 새로운 입력을 캐시에 저장
- 처음 입력했을 때

7. Output

- GPT가 생성한 답변
- 답변을 받을 때


## response.status
- completed: 응답 생성이 정상적으로 완료됨
- incomplete: 응답을 끝까지 만들지 못하고 중간에 종료됨
- failed: 오류로 인해 응답 생성 실패
- queued: 처리 대기열에 들어가 기다리는 중
- in_progress: 현재 응답을 생성하는 중
- cancelled: 요청이 취소됨

## Gradio
• 머신러닝/딥러닝 모델을 간단히 웹 애플리케이션 형태로 배포할 수 있게 해주는 파이썬 라이브러리
• 인터랙티브 웹 인터페이스를 통해 모델을 테스트하고 공유할 수 있음
