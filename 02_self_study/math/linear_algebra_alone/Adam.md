# Adam 최적화 Optimizer
**Adam**은 SGD와 다른 종류의 Optimizer입니다.

간단하게 설명하면 이전의 `gradient` 변화를 기억하고 그에 맞춰서 파라미터를 학습시켜주는 Optimizer 최적화 알고리즘입니다.

> **기울기의 방향 평균 + 기울기 크기 평균**을 정확한 수식으로 풀어보겠습니다.

## 1. 기울기 방향 누적
현재의 gradient를 $g_t$ 라고 할 경우

$$m_t = \beta_1m_{t-1} + (1-\beta_1)g_t$$

입니다.

여기에서 $m_t$는 누적된 기울기를 말하며 $m_{t-1}$ 역시 이전까지의 기울기 누적을 의미합니다. $\beta_1$는 **1차 모멘트**라는 의미를 가집니다.

해당 수식을 풀어 써보면 *총 누적 기울기는 이전까지의 기울기 합을 $\beta_1$(`1차 모멘트`)만큼 적용하고 새로운 기울기를 $1-\beta_1$ 만큼 적용한다는 것을 의미합니다.

새로운 기울기를 `1-(1차 모멘트)`만큼만 적용한다는 의미를 가집니다.

## 2. 기울기 크기 누적
기울기의 크기는 부호 없이 흔들림을 강하게 탐지하기 위해서 기울기를 제곱해서 확인합니다.

$$v_t = \beta_2v_{t-1} + (1-\beta_2)g^2_t$$

> 수식의 큰 틀은 방향 누적과 동일하며 모두 벡터를 결과로 반환합니다.

## SGD와의 비교
Adam의 업데이트를 SGD와 비교하여 보면 다음과 같습니다.

SGD:

$$w_{t+1} = w_t - \eta g_t$$

Adam:

$$w_{t+1} = w_t - \eta \frac{m_t}{\sqrt{v_t} + \epsilon}$$

의 형태가 됩니다.

> SGD는 gradient를 보고 비교적 직접적으로 활용하는 것에 비해 Adam은 계산을 더 하게 됩니다.

Adam의 핵심 수식은 $\frac{m_t}{\sqrt{v_t} + \epsilon}$ 이며 여기에서 각각의 의미는
- $m_t$ : 지금까지의 `gradient`들의 방향을 평균낸 값
- $\sqrt{v_t}$ : 지금까지의 `gradient` 제곱들의 평균
- $\epsilon$ : `0`을 분모로 가지는 것을 막기 위한 아주작은 값

이를 통해 `gradient`가 계속 커졌던 파라미터라면 $v_t$가 증가하여 학습률이 떨어지며 방향의 `음수`/`양수` 에 따라 변하는 방향이 갑자기 변하지 않게 해줍니다.

## Adam의 편향 보정
Adam에는 $\hat{m_t}, \hat{v_t}$ 라는 **bias correction**(편향 보정)을 합니다.

이는 $m_0 = 0, v_0 = 0$ 일 경우 초기 `step` 동안 값이 지나치게 0쪽으로 작아지는 문제가 있을 수 있기 때문에 다음과 같은 식으로 사용이 됩니다.

$$\hat{m_t} = \frac{m_t}{1-\beta^t_1}$$

$$\hat{v_t} = \frac{v_t}{1-\beta^t_2}$$

그리고 실제로 사용하는 최적화 식 또한 


$$w_{t+1} = w_t - \eta \frac{\hat{m_t}}{\sqrt{\hat{v_t}} + \epsilon}$$

가 되게 됩니다.

## Adam의 장단점 및 선택
Adam은 이전의 기울기 및 방향을 기억하여 하나의 극단적인 이상치가 이전 방향과 기울기를 왜곡시키는 것을 막을 수 있습니다.

### 장점
Adam의 선택 기준은 단순하게 SGD보다 좋아서가 아닌 **학습 초기에 안정적이고 빠르게 좋은 지점으로 갈 수 있어서**입니다.

보통 다음과 같은 상황에 사용합니다.
- 처음 모델을 만들고 빠르게 학습이 되는지 확인하고 싶을 때
- feature나 parameter마다 gradient 크기가 꽤 다를 때
- gradient의 노이즈가 클 때
- baseline를 빠르게 구축할 때

사용할 수 있습니다.

### 단점
하지만 Adamd은 연산이 더 많은만큼 메모리와 계산을 더 많이 사용하게 됩니다.

또한 특정 문제에서는 SGD와 Momentum을 이용해서 튜닝한 모델의 성능이 더 좋은 경우가 나오기도 합니다.
