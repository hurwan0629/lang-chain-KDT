선형대수학은 보통 다음 순서로 배우면 자연스럽게 연결돼. 교재마다 행렬식을 조금 앞당기거나 뒤로 미치는 차이는 있어.

* 시그마 기호
* 삼각함수: (\sin,\cos)
* 기초 미분: 최적화나 머신러닝까지 연결할 경우

* 연립방정식을 행렬로 표현하기

  ]
* 계수행렬
* 첨가행렬
* 기본 행 연산
* 가우스 소거법

## 4. 역행렬

* 역행렬의 정의
  [
  AA^{-1}=A^{-1}A=I
  ]
* 역행렬의 존재 조건
* 가우스-조던 소거법으로 역행렬 구하기

  [

  ]

  [
  (AB)^{-1}=B^{-1}A^{-1}
  ]
* 특이행렬과 비특이행렬

실제 계산에서는 역행렬을 직접 구하는 것보다 소거법이나 행렬분해로 (Ax=b)를 푸는 경우가 많아.

## 5. 행렬식

* (2\times2), (3\times3) 행렬식
* 여인수와 소행렬식
* 여인수 전개
* 행 연산과 행렬식의 관계
* 곱의 행렬식
  [
  \det(AB)=\det(A)\det(B)
  ]
* 역행렬 존재 조건
  [

  ]
* 행렬식의 기하학적 의미

  * 면적·부피의 확대 비율

* 크래머 공식

행렬식은 행렬이 공간을 얼마나 확대·축소하고, 차원을 붕괴시키는지 보여주는 값이야.

## 전체 흐름만 압축하면

[
\boxed{
\text{벡터}
\rightarrow
\text{행렬}
\rightarrow
\text{연립방정식}
\rightarrow
\text{벡터공간}
\rightarrow
\text{선형변환}
\rightarrow
\text{직교·정사영}
\rightarrow
\text{고유값·대각화}
\rightarrow
\text{행렬분해·SVD}
\rightarrow
\text{PCA·회귀·머신러닝}
}
]

지금 공부 중인 **회전행렬, 내적, 공분산 행렬**은 각각 선형변환, 직교성, 데이터 응용 단계에 걸쳐 있어. 따라서 공분산 행렬이 어렵다면 먼저 `벡터 → 행렬곱 → 선형결합 → 기저 → 정사영` 부분을 확실히 잡는 게 가장 효과적이야.
