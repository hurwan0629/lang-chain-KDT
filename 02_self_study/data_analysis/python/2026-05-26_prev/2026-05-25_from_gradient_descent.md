# 경사 하강법
지금까지는 행렬곱을 통한 예측갑을 목표값과 비교하여 `loss`값을 찾는 방법이였습니다.

이때, `loss`를 줄이기 위해 `w`를 어떤 방향으로 바꾸어야 하는지를 알기 위해 **경사하강법**을 사용합니다.

쉽게 말하면 `loss`가 줄어드는 쪽으로 `W`를 수정하게 됩니다.

예를 들어 현재 `W1`에 대한 결과가 `loss=10`일 경우, `W2`로 하였을 때 `loss=13`이되고, `W3`으로 하여 `loss=7`이되면 경사하강법은 수학적으로 계산해서 `loss`가 가장 빨리 줄어드는 방향으로 `W`로 움직이게 됩니다.

### 핵심 식
`W = W - [learning_rate] x [gradient]`가 됩니다.

기존 가중치에서 증가하는 방향으로 `leaning_rate`만큼 움직이게 됩니다. 그렇게 오차만큼 `-` 해주는 방식으로 천천히 값을 수렴시켜 갑니다.

## 한계
하지만 **경사하강법의 핵심 한계**는 봉우리 지형이 여러개가 존재할 시 하나의 구덩이 저점으로 갈 시에 다시 나올 수 없는 것입니다. 이것을 `지역 최솟값`(`local minimum`)문제 라고 하빈다.

## 해결법
이것을 실제로 해결한다기 보다는 **좋으 곳에 도달할 확률을 높이는 방법**들을 사용합니다.


### 1. SGD의 랜덤성 - Stochastic Gradient Descent
전체 데이터를 한번에 보고 내려가는게 아니라 일부 데이터만 보고 조금씩 내려가면 움직임에 흔들림이 생기게 됩니다. 전체 데이터 기준 경사 하강법은 너무 정직하게 내려가기 때문에 SGD를 이용하여 약간 흔들리면서 내려가는 방식을 채택하게 됩니다.

### 2. learning rate 조절
처음에는 크게 움직이고, 나중에는 작게 움직이면서 처음에는 큰 범위에서 낮은 부분의 범위 속에서 더 세분화된 낮은 위치를 찾는방식입니다. 물론 그 사이에 틈이 있을 수 있지만 문제를 어느정도 해결해줍니다.

### 3. Momentum
기울기만 보는 게 아니라, 이전에 움직이던 방향의 관성도 같이 사용합니다. 이전에 강하게 내려가고 있었더라면 어느정도의 높이는 그냥 다시 올라가면서 심하지 않은 한 상대적으로 낮은 봉우리는 넘어갈 수 있습니다.

### 4. Adam같은 optimizer
`Adam`은 실무에서 많이 쓰는 최적화 방식입니다.
> learning rate를 가중치별로 적절히 조절해주는 optimizer
으로 처음 딥러닝 할 때는 보통 `Adam(model.parameters(), lr=0.001)`으로 시작하는 경우가 많다고 합니다.

## saddle point
골짜기 갇힘도 있지만 다른 문제도 많이 생깁니다.

`saddle point`라는 어떤 방향으로는 내려가고 어떤 방향으로는 올라가는 지점을 말합니다.

한 방향에서는 골짜기처럼 보이지만 다른 방향에서는 봉우리처럼 보이는 형태입니다.

![saddle point 예시](https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcTRGbex1DHwkYEDfyZh4QHS1BpldOV62qBK4Q&s)

위 사진에서 한 방향으로 최저점에 도달하여 수학적으로 더이상 `loss`값을 줄이지 않고 그대로 두는 현상이다. (실제로는 z축으로 이동해서 줄일 수 있다.)

이는 실제로 해당 점의 주변의 기울기가 모두 `0`이기 때문에 수학적으로 **평평한** 위치이기 때문입니다.

### Momentum
위와 동일하게 관성을 준다
### Noise
미세하게 변화를 주어 미끌어져 내려오게 한다.

## 역전파 backpropagation
위에 경사 하강법들은 여러 값을 시도하여 경사도가 더 높은쪽으로 떨어지는 방식으로 `W`를 수정했습니다.

이때, 수많은 `W`중에서 `loss`에 영향을 준 `W`를 어떻게 찾는지에 대해서 계산하는 과정이 **역전파**입니다.

원래 기존에
`X · W1` 에서 `W2`를 가중하면 결과에 가까워 진다 할 때 
`X · W1 · W2`가 되는 방식으로 점점 가중치를 결과에 가깝게 조절하는 방식입니다.

여기에서 `Wn`은 수천, 수만개가 될 수 있기 때문에 랜덤으로 찍어보면 너무 비효율적이 됩니다.

이를 해결하기 위해 지속적으로 `loss`가 줄어드는 방향으로 계산해서 이동하게 됩니다.

`W`가 2개 이상일 경우
`X1 > W1 > X2 > W2 > ... > Y > loss`가 되게 되는데 `W1`은 `loss`에 직접 닿아있지 않기 떄문에 `loss`에 영향을 얼마나 줬는지를 `W1`에 대해서 파악하기 어렵습니다.

이 때 결과가 틀리게 나옸왔을 경우에, 어떤 가중치가 이를 틀리게 만들었는지를 알기 위해 `Wn`부터 `W1`까지 내려오면서 조금씩 수정해보면서 더 값에 근접하게 결정하게 됩니다.

## 역전파의 효율성
저는 아래와 같은 문제를 제시했습니다.
1. 그렇게 하면 W가 늘어날수록 기하급수적으로 볼게 많아지지 않나요?
    > 랜덤으로 다 시도해보면 W1,2,3 에 100가지씩 시도하면 100만가지가 생기게 됩니다. 이 문제를 해결하기 위해 어떤 **방향**으로 갈 것인지에 대한 연산을 하게 됩니다.
2. 그냥 역전파 대신 W 하나 더 추가하면 안되나요?
    > W를 추가하는건 모델을 복잡하게 만들기 때문에 모델을 학습시키는 과정에는 `W`를 쓰지 않습니다. `W` 추가는 **모의 구조를 구할 때** 고려하게 됩니다.
3. W를 바꾼다 해도 실수 범위 내에서 뭐든 바꿀 수 있을텐데 어떻게 값을 어디로 바꿀건지 결정하나요?
    > `gradient`(기울기)를 통해 구하게 됩니다. (`- 기울기 * 가중치`)

# 활성화 함수
지금까지 본 것은 `신경망`에 대한 것입니다.
하짐나 `X · W1 · W2 · W3 ... `같이 쌓다보면 결국은 하나의 선형 계산과 크게 다르지 않게 됩니다. 이는 신경망이 복잡한 패턴을 배우기 어렵게 만듭니다.

**활성화 함수**란 **중간 계산값에 끼워넣는 함수**입니다. 모습은 `X · W + b` + `활성화 함수(ReLU)` + `다음 가중치` + `...` 과 같은 형태입니다. 이를 통해 **복잡한 패턴을 배울 수 있게**해줍니다.

대표적인 함수가 **`ReLU`**로, `x`가 양수면 그대로 두고, `x`가 음수면 `0`으로 만드는 함수입니다. 이를 통해 중요하지 않은 특징의 경우 값을 `0`으로 만들어버리는 역할을 합니다.

예를 들어 귀모양을 찾을 떄, `ReLU` 후 `0`이면 귀가 아니라 판단하고 `양수`면 다음층으로 전달하는 형태입니디.

다른 활성 함수로는
- `Sigmoid`: 값을 0~1 사이로 만듭니다.
- `Tanh`: 값을 `-1` ~ `1` 사이로 만듭니다.
- `ReLU`: 음수는 `0`, 양수는 그대로 만듭니다
- `Leaky_ReLU`: 음수를 아주 조금 살립니다.
- `GELU`: Transformer 계열에서 자주 볼 수 있습니다.

## 1. 과정
**입력층**은 데이터가 들어오는 공간으로 앞에서의 `X`를 말합니다. 데이터가 100개 있다면 순서대로 1번 데이터부터 100번까지 순서대로 들어오게 됩니다.

이렇게 들어온 데이터들은 **은닉층**의 가중치와 활성함수를 통해 특징을 늘리게 됩니다.

예를 들어서 **가중치**를 통해 [주가, 어제 가격, 뉴스] 3가지 데이터에 대한 [예측 고가, 예측 저가, 예측 시장 반응, 예측 금리] 와 같이 4가지의 특징으로 나눌 수 있습니다.

이후에는 **활성함수**를 이용하여 복잡한 패턴에 대한 적응을 할  수 있게 합니다.

최종적으로 **출력층**에서 결과를 만들어내고, 원하는 데이터 종류들에 따른 열의 개수를 가진 행, 예를 들어 `매수(0)`/`매도(1)`을 선택하고 싶다면 (100, 1)의 결과가 나올 수 있습니다.

# 뉴런 개수 / 모델 용량
지금까지 모델을 만드는 방법을 알아보았습니다.
예를 들어
- 입력 속성: 5개
- 활성화 함수: ReLU
- 은닉층 뉴런: 5개
- 출력 종류: 3개 로 한다면
```python
nn.Linear(5, 5)
nn.ReLU()
nn.Linear(5, 3)
```
와 같은 형태가 됩니다.

뉴런 개수가 많으면 모델이 더 복잡한 패턴을 배울 수 있습니다. 예를 들어서 `내가 밥을 샀다 > 밥을 먹어 기분이 좋아졌다 > 돈이 없어서 기분이 안좋아졌다 > 그래도 필요 지출이라 생각하니까 좀 나아졌다` 와 같이 말이다. 이건 대충 봤을 때 중간 뉴런이 2개라고 생각할 수 있다.

### 적절한 은닉층 뉴런 개수

하지만 **뉴런 개수가 과하게 많으면** 데이터에 대한 결과를 그냥 외워버릴 수 있습ㄴ디ㅏ. 이때문에 좋은 모델은 패턴을 아는 것입니다. (정확히는 a는 A로, b는 B로, ... n은 N으로 가게끔 최적화 되는 현상. 이때 새로운 값 ? 이 들어오면 오차가 커질 수 있음)

빈대로 **뉴런이 너무 적으면** 모델이 너무 단순해서 학습 데이터도 제대로 맞추지 못하는 (차원 수가 부족해서 여러개의 특성을 한번에 맞추는 것이 불가능) 상태가 될 수 있습니다.

**적절한 은닉층 뉴런 개수**는 작은 모델로 시작해서 슬슬 맞추기 시작할 때 과적합을 경계하며 필요한 뉴런을 늘리는 방식으로 이루어집니다.

적합한 모델제작을 위해 일반적으로 데이터를 3가지로 나누게 됩니다.
- `train data`: 훈련용 데이터 (훈련에 쓰일 예측 결과값)
- `validation data`: 한번 중간에 방향이 잘 되고 있는지 (중간 결과)
- `test data`: 최종 데이터 셋으로 여기에서 모델을 쓸지, 말지를 결정합니다.

이는 훈련용만으로 만들게 되면 샘플 데이터들에 최적화 된 데이터들이 만들어 지는 것을 방지하기 위해서이며, 너무 잘 만들다가 한번 축으로 삼기 위해 중간 결과 (`validation data`) 데이터를 만들어주는 방식입니다.

또한 데이터셋을 `a`, `b`, `c`, ..., `n` 형태로 나누어 교차검증을 할 수 있습니다. 이를 `K-Fold Cross Validation`이라고 합니다. 이때도 **test set**는 따로 남겨두어서 확인을 하게 됩니다.
