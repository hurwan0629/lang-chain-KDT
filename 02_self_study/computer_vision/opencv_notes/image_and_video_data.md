### 이미지와 영상
우선 이미지부터 이야기를 하면서 시작하겠습니다.

이미지는 2차원 배열로 구성되어있습니다.

보통 2차원의 `H, W` 프레임 크기와 함께 `RGB`, `HSV`, `GrayScale` 등에 따른 다른 채널 개수/표현으로 구성됩니다.

OpenCV 기준에서는 하나의 이미지 데이터의 순서는 `(H, W, C)` 로 이루어져 있으며 `GrayScale`의 경우에는 `(H, W)` 로 이루어집니다.

또한 영상의 경우에는 이미지 여러장을 시간 순서대로 보여주는 것입니다.

영상에는 다음과 같은 정보가 들어있습니다.
- fps: 어떤 속도로 다음 이미지를 보여줄 것인지 (Frame Per Second)
- frame: 영상을 구성하는 여러 이미지중 하나의 이미지입니다.
- time: 몇번째 또는 어떤 시점에 배치되는지에 대한 정보입니다.
- Codec: `COder + DECoder` 에서 나온 말로 여러장의 이미지 데이터를 압축하며 이를 디코딩하는 알고리즘을 뜻합니다. 대표적인 알고리즘은 다음이 있습니다.
  - `H.264`: 흔하며 호환성 좋음
  - `H.265 / HEVC`: `H.264`보다 더 높은 압축률 + 높은 연산량
  - `VP9`: 높은 압축 효율 및 최신
  - `MJPEG`: 각 프레임을 JPEG처럼 압축. 단순하고 용량이 큼
  - *대표적인 인코딩 개념은 여러 이웃 프레임에서 변경된 정보를 표현하는 방식이 존재합니다.*
- Encoding & Decoding: Codec 규칙을 이용하여 데이터를 압축 및 해석하는 과정을 말합니다.

아래에서 이를 구성하는 요소에 대해서 더 상세히 알아보도록 하겠습니다.

### I / P / B 프레임
압축에는 여러 이미지 개념이 존재합니다.
- I-Frame: 독립적인 완전한 이미지에 가까움
- P-Frame: 이전 프레임을 참고하여 변형된 데이터
- B-Frame: 이전 + 이후 프렐임을 참고합니다.

> 아래로 갈수록 복원을 위해서 다른 프레임의 영향을 크게 받습니다.

### FourCC
FourCC는 `Four Character Code`라는 4글자로 식별된 코ㅗ드를 말합니다.

OpenCV에서는 다음과 같은 문법으로 표현하게 됩니다.

```py
# * 연산자는 *"mo4v" == "m", "p", "4", "v"로 풀어주는 언패킹 연산자입니다.
fourcc = cv2.VideoWriter_fourcc(*"mp4v")

fourcc = cv2.VideoWriter_fourcc(*"H265")
```

**주의할 점**으로는 FourCC와 Codec를 동일시하면 안된다는 점입니다.

FourCC는 Codex/영상 포맷을 식별하기 위한 코드에 더 가까워 `H.265` 계열도 환경이나 Container에 따라서 `H264`, `X265`, `avc1`과 같은 식별자로 나타날 수 있습니다.

따라서 Codec는 압축 기술, FourCC는 그 기술을 나타내기 위해서 사용되는 식별 코드라고 할 수 있습니다.

### Container
**Container Format**는 여러 데이터를 담는 상자를 의미합니다.

예를 들어서 `.mp4`가 있으면 그 파일 안에는 다음과 같은 정보가 존재할 수 있습니다.

```md
# video.mp4
- VideoStream: H.264
- Audio Stream: ACC
- Subtitle: 부제목
- Metadata
  - 지속 시간
  - 생성 시간
  - 등등
```

> Container의 종류에 따라 여러가지 내부 Codec가 존재할 수 있습니다.

### Pixel Format
픽셀의 종류에도 `BGR`, `RGB`, `GrayScale`, `HSV`, `YCbCr` 등과 같은 표현 방식이 있으며 예를 들어 `RGB`는 흔히 아는 빨강, 초록, 파랑을 의미하며, `YCbCr`은 순서대로 밝기, 파랑, 빨강을 의미하는 방식으로 셀들이 구성되게 됩니다.

### 평활화
평활화는 데이터를 저장하는 방식이 아닌, 셀들의 분포가 한쪽으로 몰려있을 때, 이를 골고루 분포하게 만들어주는 기술을 말합니다.

평활화에는 크게 2가지가 존재합니다.
1. 히스토그램 평활화: 명암 분포를 고르게 만드는 것
2. 공간적 평활화: 주변 픽셀을 이용해서 노이즈를 줄이는 것

### 히스토그램 평활화 
이는 CDF(누적 분포)를 이용하여 밝기 정보들을 넓게 펼쳐주는 방식을 말합니다.

이는 결국 이미지를 명암 대비로 크게 만들어주는 효과를 만들어줍니다.

이는 특정 밝기 값에 대해서 그 밝기보다 작은 밝기들의 비율만큼 새로운 범위로 재배치하는 방식을 말합니다.

```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

result = cv2.equalizeHist(gray)
```

### Smoothing 평화화
이미지의 픽셀값이 한쪽만 툭 튀어나와 있는 경우, 주변 픽셀값들을 참고하여 부드럽게 만드는 것을 의미합니다.

주된 목적은 다음과 같습니다.
- 노이즈 제거
- 작은 변화 제거
- 이미지를 부드럽게 만들기

이때 평활화를 위해 이동시키면서 계산을 해주는 **커널**이라는 작은 행렬 (보통 `3x3`, `5x5`)이 존재합니다.

커널은 아래 2가지를 통해 이미지의 전체 데이터를 새롭게 계산해줍니다.
- 행렬의 위치별 값
- 계산 방식

- 평균 블러: 커널 크기만큼의 픽셀들의 평균을 구해서 가운데 픽셀로 사용하게 됩니다. 단순하고 빠르지만 경계선까지 많이 흐려집니다.
- 가우시안 블러: 가운데 픽셀쪽으로 갈수록 더 높은 가중치를 주어 평균을 구합니다. 특별한 이유가 없다면 노이즈 제거에 많이 사용됩니다.
- 중앙값 블러: 픽셀들을 정렬하여 중앙값을 사용합니다. `Salt-and-Pepper-Noise`라는 흰색/검정 픽셀이 튀는 노이즈를 해결하는데 좋습니다.

```python
# 평균 블러
mean_blur1 = cv2.blur(img, (3, 3))
mean_blur2 = cv2.boxFilter(img, -1, (3, 3))

# 가우시안 블러 (3번째 인자를 0으로 하면 opencv가 계산할 요소들을 기준으로 sigma를 자동 결정)
gaussian_blur = cv2.GaussianBlur(img, (3, 3), 0)

# 중앙값 블러 (숫자 하나만 사용)
median_blur = cv2.medianBlur(img, 3)
```
