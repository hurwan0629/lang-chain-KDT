# 학습 방식 피드백

이 파일은 학습 방식에 대한 사용자 피드백과 그에 따른 진행 방식을 기록한다. 새 피드백이 나오면 날짜와 함께 추가한다.

## 2026-11-08

- Python 기본기(`dict`, `list`, `set`, 데코레이터 등)와 프로젝트에서 자주 쓰는 도구(`shutil`, YAML, `argparse`, `torch` 등)를 익히고 싶다.
- 직접 사용해 감을 잡은 뒤, 추상화 방식과 내부 구조의 핵심을 배우고 다시 실전에 적용하고 싶다.
- 이미 이 프로젝트에서 `pathlib`, JSON, YAML, `argparse`, `dataclass`, 로깅, 예외 처리 등을 조금 연습했다. 기존 프로젝트에서 이어서 진행하길 원한다.
- 예제를 몇 차례 직접 입력한 뒤 문제를 풀거나 코드를 직접 작성하는 방식을 원한다.
- 의미 없이 코드를 따라 입력하는 방식은 흥미가 떨어진다. 각 연습에 목표를 두고, 입력하는 코드로 무슨 일이 일어나는지 이해하며 진행하길 원한다.

## 다음 수업에 적용할 방식

1. 기존 프로젝트 코드와 연결되는 작은 목표를 제시한다.
2. 실행 전 결과를 예상하고, 실행 후 파일이나 출력에서 변화를 확인한다.
3. 필요한 코드만 직접 입력해 본 뒤 비슷한 문제를 스스로 해결한다.
4. 작성한 코드를 함께 검토하고, 관련 내부 구조와 추상화의 핵심을 설명한다.
5. 같은 개념을 조금 바꾼 실전 과제로 다시 적용한다.

현재 목표: `dataclass__logging_try_except.py`의 설정 저장 흐름을 살펴보고, 이전 설정을 백업하는 기능을 직접 구현한다.
