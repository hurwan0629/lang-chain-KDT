# 99 Legacy

기존 구조, 루트 문서, IDE 설정, 개인/메타성 자료를 보존하는 영역입니다.

## Folders

- `root_docs/`: 기존 루트 `README.md`, `AGNETS.md`
- `ide/`: 기존 `.idea`
- `agents/`: 기존 `.agents`
- `workspace_meta/`: 기존 `workspace` 내부 메타 폴더
- `docs_remaining/`: `docs/blog` 외의 기존 docs 잔여 자료
- `private/`: 기존 private 폴더
- `logs/`: 개인 질의/학습 로그
- `personal_documents/`: 개인 문서류
- `original_workspace_remaining/`: 기존 workspace 잔여 구조

## Notes

이 영역은 삭제 대상이 아닙니다. 공개 저장소에 올리기 전에는 `private/`, `logs/`, 메타 폴더의 포함 여부를 별도로 확인해야 합니다.
