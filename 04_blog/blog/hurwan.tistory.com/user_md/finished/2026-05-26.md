# 지금까지 한 일 정리

블로그에 넣지 않은 작업들이

0. 탐색적 데이터 분석의 여러 도표들 알아보았고, 마무리로 데이터의 기초 분석의 중요성을 강조받았다.
1. 문자열에 대해서 f-string, `%` 표현법, `.format()` 에 대해서 정리를 하였는데 일단 별건 아닌거같아서 중요하게 다루지 않아도 될 듯 함. 그냥 재미삼아 움직이는 "hello" 출력
2. 이번에 `데이터 과학을 위한 통계 2판`의 2장을 읽었는데 `1장 탐색적 데이터 분석`이후에 표본 추출에 관한 내용을 읽었다.

기본적으로 **임의 표본 추출**을 통해 전체 모집단에서 표본을 추출해내며 조금 더 정확한 조건을 걸기 위해서는 **층화표본추출**, **표본 편향**등에 대한 용어들을 알았고, 역사 사건의 일례로 표본 대상의 선정이 매우 중요하다는 것을 알게 되었다.

3. 개인적으로 궁금했던 해싱과 여러 기법들에 대해서 알아보았다.

해싱은 데이터를 정수값으로 만드는 과정이였으며

기본적으로
- 충돌 회피
- 충돌 대처

방식으로 나뉘며

회피의 경우에는 애초에 부딛히지 않게 해시함수, 해시테이블 크기, 채워짐에 따라 크기 키워주기 가 있고,

대처의 경우에는 한 인덱스에서 이어붙이는 체이닝, 계속 더해가는 오픈 어드레싱,

애초에 좀 더 체계적인 분산 방식으로 이중해싱을 사용할 수 있습니다.

파이썬은 추가로 perturb로 노이즈를 주는 방식을 사용하기도 합니다.


이외에도 여러가지 방식을 알았습니다.

- Robin Hood Hashing: 멀리 밀려난 값에 우선권 주기.
- Cuckoo Hashing: 두개 이상의 위치 후보를 갖는 방식.
- Hopscotch Hashing: 값을 원래 근처에 최대한 두는 방식.
- Perfect Hashing: 충돌이 아예 없도록 해시함수 만들기. (저장할 값이 정해져있을 때 사용 가능)
