# 01 Class

수업 중 작성한 코드, 실습 파일, 수업 일지를 모아둔 영역입니다.

## Folders

- `class_diary/`: 수업 일지와 HTML 변환 결과
- `python/`: Python 기초 수업 자료
- `crawling/`: requests, BeautifulSoup, Selenium, 크롤링 과제
- `html_css/`: HTML/CSS 수업 및 과제
- `javascript_node/`: JavaScript, Node, Express, EJS, MongoDB, Socket.IO 수업 흐름
- `api_fastapi/`: FastAPI 및 API 서버 실습
- `machine_learning/`: scikit-learn, 회귀/분류, 데이터셋 기반 ML 실습
- `deep_learning/`: PyTorch, CNN, AlexNet, 모델 학습 실습
- `computer_vision/`: OpenCV, 이미지/영상 처리, 객체 검출 수업 자료

## Sorting Rule

원래 폴더명이 실제 내용과 맞지 않는 경우 실제 내용 기준으로 이동했습니다. 애매한 자료는 `90_uncertain/`에 남겼습니다.
