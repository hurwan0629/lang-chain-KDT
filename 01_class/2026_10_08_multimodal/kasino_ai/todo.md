# **3. 슬롯머신 AI 개발**
- 가장 많은 보상을 획득하는 AI 에이전트 만들기
- 카지노에 있는 5개의 슬롯머신 중 가장 높은 당첨 확률을 가진 머신을 스스로 찾아내는 AI 프로그램을 개발
- 각 슬롯머신은 서로 다른 당첨 확률을 가지고 있지만, AI 에이전트는 어떤 머신이 가장 유리한지 알지 못함
- 에이전트는 슬롯머신을 직접 선택하고, 당첨 여부를 확인하면서 각 머신의 당첨 확률을 추정해야 함
- 최종 목표는 1000번의 행동 동안 가능한 한 많은 보상을 획득하는 것

1. 슬롯머신 환경 구현
- Python과 Numpy를 사용
- 슬롯머신 총 5개
- 실제 당첨 확률은 [0.2, 0.5, 0.1, 0.8, 0.3]으로 설정
- 슬롯머신을 선택하면 당첨 시 1, 실패 시 0의 보상을 반환하도록 구현
- AI 에이전트는 실제 당첨 확률을 직접 참조하여 행동을 선택해서는 안됨

2. AI 에이전트 구현
- Random 전략: 5개의 슬롯머신 중 하나를 무작위로 선택
- Greedy 전략: 지금까지 획득한 보상을 기반으로 가장 높은 평균 보상을 가진 슬롯머신을 선택
- Epsilon-Greedy 전략: 일정 확률로 무작위 슬롯머신을 선택하고 나머지 확률로 현재 가장 높은 평균 보상을 가진 슬롯 머신을 선택 (엡실론 값은 0.1과 0.01을 각각 적용)

3. 학습 기능 구현
AI 에이전트는 슬롯머신을 선택할 때마다 아래 정보를 업데이트해야 함
- 각 슬롯머신을 선택한 횟수
- 각 슬롯머신의 평균 보상 추정값
- 매 행동에서 획득한 보상
- 지금까지 획득한 누적 보상

> 평균 보상은 기존 데이터를 모두 다시 계산하지 않고 이전 평균과 새로 획득한 보상을 이용하는 방식으로 구현

4. 전략별 실험
> 각 전략을 1000번씩 실행하고 아래 결과를 출력
- 최종 누적 보상
- 슬롯머신별 선택 횟수
- 슬롯머신별 추정 당첨 확률
- 가장 많이 선택한 슬롯머신 번호
